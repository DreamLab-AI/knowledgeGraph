- ### Definition
  - An open protocol that uses the HTTP 402 Payment Required status code to enable machine-to-machine payments for accessing web resources and services. It allows clients to pay programmatically before a request is served.

- ### Content
  - The X402 protocol revives the long-reserved HTTP 402 status code so that servers can request payment and clients can supply proof of payment within the standard request and response flow.
  - It is aimed at enabling pay-per-use access and agent-driven commerce, where software clients settle small payments, typically in stablecoins, without manual checkout steps.
