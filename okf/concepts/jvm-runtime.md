# JVM Runtime

The JVM runtime is the execution environment provided by the Java Virtual Machine, which loads, verifies and runs platform-independent bytecode. It supplies just-in-time compilation, automatic garbage collection, threading and a security model that isolates executing code. The JVM hosts many languages beyond Java, including Kotlin and Scala, and underpins several enterprise blockchain platforms.
