# Network Effects

Network effects describe the phenomenon whereby a product or service gains additional value for each existing user as the number of participants increases, creating a self-reinforcing growth dynamic. Direct network effects arise when users directly benefit from others on the same platform; indirect effects emerge when complementary products or services multiply with scale, creating cross-side externalities.
