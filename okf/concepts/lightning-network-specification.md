# Lightning Network Specification

The Lightning Network Specification, known as BOLT (Basis of Lightning Technology), is the set of documents defining the peer-to-peer protocol for Bitcoin's Lightning payment-channel network. It standardises channel establishment, commitment transactions, HTLC-based routing, onion message encryption, and gossip propagation so that independent implementations interoperate. The specification is the canonical reference enabling trust-minimised off-chain Bitcoin payments.
