# C4 Model

The C4 Model is a hierarchical software architecture notation system developed by Simon Brown that uses four abstraction levels — Context, Containers, Components, and Code — to describe and communicate the structure of a software system at progressively increasing levels of technical detail. Each level targets a different audience, from non-technical stakeholders at the Context level to developers at the Code level, using a minimal, tool-agnostic set of diagram elements that are easy to reason about and keep up to date.
