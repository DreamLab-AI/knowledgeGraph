# Machine Translation

Machine Translation is the automated translation of text or speech from one natural language to another using neural network models, particularly transformer-based sequence-to-sequence architectures. Modern neural MT systems achieve near-human quality through pre-training on massive multilingual corpora, cross-lingual transfer learning, and attention mechanisms that model long-range linguistic dependencies.
