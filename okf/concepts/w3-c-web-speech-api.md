# W3C Web Speech API

The W3C Web Speech API is a browser interface specification that exposes speech recognition (speech-to-text) and speech synthesis (text-to-speech) to web applications through standardised JavaScript objects. It lets pages capture spoken input and produce spoken output without bespoke plugins, underpinning voice-driven and accessibility features on the web. Implementation depth and recognition backends vary across browsers, with some delegating recognition to cloud services.
