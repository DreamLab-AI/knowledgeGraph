# Wheeled Mobile Robot

A mobile robot that uses wheels as its primary locomotion mechanism, enabling efficient navigation on flat or structured surfaces. Wheeled mobile robots span applications from industrial logistics and warehouse automation to outdoor infrastructure maintenance, typically combining SLAM-based navigation, sensor fusion, and modular payloads.
