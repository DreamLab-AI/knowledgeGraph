# Accountability Event

An accountability event is an evaluative record that assesses one executed action for correctness, authorisation and compliance.[^1] It is distinct from the runtime event it evaluates, which is a [[Ledger Event]]; the property `linkedLedgerEvent` joins the two. visionGraph places it under [[Event]].
