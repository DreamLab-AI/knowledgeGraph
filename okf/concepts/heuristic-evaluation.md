# Heuristic Evaluation

Heuristic evaluation is a usability inspection method in which a small number of expert evaluators judge an interface against a set of recognised usability principles, or heuristics, to identify usability problems. It is a discount technique that requires no test participants, producing a ranked list of issues with severity estimates. Because it depends on evaluator expertise rather than observed user behaviour, it complements, rather than replaces, empirical usability testing.
