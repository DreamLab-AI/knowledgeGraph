# Visual Question Answering

Visual question answering (VQA) is a multimodal AI task in which a system produces a natural-language answer to a free-form question posed about an image or scene. It requires jointly grounding linguistic semantics in visual content, combining object recognition, spatial reasoning, and language understanding. VQA is a benchmark capability for vision-language models and a building block for assistive and augmented-reality interfaces.
