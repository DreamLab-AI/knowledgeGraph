# User Context Awareness

User Context Awareness is the capability of digital systems to sense, model, and respond to a user's current situation—encompassing location, activity, device state, social context, and environmental factors—in order to deliver personalised, timely, and relevant experiences. It underpins adaptive XR interfaces, smart environment switching, and context-driven content recommendation in spatial computing.
