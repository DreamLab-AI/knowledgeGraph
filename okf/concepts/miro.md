# Miro

Miro is a cloud-based collaborative whiteboard platform that provides an infinite canvas for distributed teams to brainstorm, diagram, map workflows, and run workshops in real time. It offers sticky notes, templates, frameworks, and integrations with tools such as Jira, Slack, and design suites. It is widely adopted for product discovery, agile ceremonies, and remote facilitation.
