# RFC 5280

RFC 5280 is the IETF standard that defines the Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) profile. It specifies the structure, encoding, and processing rules for X.509 v3 certificates and v2 CRLs, including the required and optional extensions and the certification path validation algorithm. The document is the normative reference that governs how PKI implementations issue, encode, and validate certificates on the public Internet.
