# Agent Contract Set

An agent contract set is the collection of contracts attached to an AI agent, declared as `ContractSet` in the Agent Ontology.[^1] The Agent Ontology declares the class without a definition; this one follows from its properties. visionGraph places it under [[Configuration]], with [[Agent Contract]] as its part.
