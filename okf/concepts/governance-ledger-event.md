# Governance Ledger Event

A governance ledger event is a ledger event that represents governance or specification update events, declared in the Agent Ontology as `GovernanceLedgerEvent` and a subclass of [[Ledger Event]].[^1] It is the counterpart of the [[Runtime Ledger Event]]: where the runtime kind records what an agent did, the governance kind records changes to the rules and specifications around it.
