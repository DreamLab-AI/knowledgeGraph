# Key Management System

A key management system (KMS) is a service or appliance that generates, stores, rotates, distributes and revokes cryptographic keys over their full lifecycle. It enforces access policies and isolates key material, often backed by hardware security modules, so that applications can perform cryptographic operations without directly handling private keys. A KMS is foundational to secure identity, encryption and digital-asset custody.
