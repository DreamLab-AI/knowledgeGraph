# Google Cloud

Google Cloud (formally Google Cloud Platform, GCP) is a suite of public cloud computing services operated by Google LLC, providing infrastructure-as-a-service (IaaS), platform-as-a-service (PaaS), and software-as-a-service (SaaS) offerings spanning compute, storage, networking, data analytics, and artificial intelligence. It is built on the same global infrastructure that powers Google Search, YouTube, and Google Workspace, spanning a worldwide network of data centres connected by Google's private fibre backbone. Google Cloud competes directly with Amazon Web Services and Microsoft Azure as one of the three dominant hyperscale cloud providers, and differentiates through deep integration of AI/ML capabilities via Vertex AI, TPU accelerator hardware, and pre-trained foundation models such as Gemini.
