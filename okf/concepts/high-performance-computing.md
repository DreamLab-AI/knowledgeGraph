# High-Performance Computing

High-Performance Computing (HPC) refers to the use of aggregated computational resources — clusters, supercomputers, and massively parallel systems — to solve problems requiring sustained compute throughput, memory bandwidth, or I/O rates far beyond those achievable on commodity servers. HPC systems combine specialised processors (CPUs, GPUs, FPGAs, TPUs), high-speed interconnects (InfiniBand, NVLink), parallel file systems, and workload-management software to execute scientific simulations, large-scale machine learning training, genomics, climate modelling, and computational fluid dynamics at peta- or exascale performance.
