# GitHub

GitHub is a web-based platform for hosting Git repositories that provides version control, code review, issue tracking, project management, and collaborative software development features. Acquired by Microsoft in 2018, it serves as the primary distribution hub for open-source software and integrates CI/CD via GitHub Actions, package registries, and an extensible API and webhook ecosystem.
