# Token Economy

A token economy is an economic system in which digital tokens — cryptographic representations of value, rights, or access — serve as the primary medium of exchange, incentive, and governance within a defined platform or protocol. Token economies leverage blockchain infrastructure to create programmable, permissionless economic systems where tokens encode ownership (utility tokens, security tokens, governance tokens, NFTs), align participant incentives through staking and reward mechanisms, and enable decentralised governance. The concept spans DeFi protocols, Web3 platforms, creator economies, and emerging AI agent economies.
