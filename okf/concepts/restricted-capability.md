# Restricted Capability

A restricted capability is an [[Agent Capability]] whose exercise is limited, and it is the sibling of [[Critical Capability]]. The two classes are disjoint: no capability is both critical and restricted. The Agent Ontology declares the class without a definition; this one follows from its parent and the axiom that involves it.[^1]
