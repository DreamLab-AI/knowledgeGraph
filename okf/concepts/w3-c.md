# W3C

The World Wide Web Consortium (W3C) is the principal international standards organisation for the World Wide Web, founded by Tim Berners-Lee in 1994 and operating through a global membership model to develop open, interoperable web standards. W3C produces technical specifications, guidelines, and software that define the core technologies of the web including HTML, CSS, SVG, XML, RDF, and the semantic web stack. Its standards process emphasises consensus, royalty-free licensing, and broad implementability across browsers and platforms.
