# LP Token

An LP (Liquidity Provider) token is a fungible cryptographic token minted by a decentralised exchange or liquidity pool smart contract to represent a depositor's proportional ownership stake in a pool's combined assets, accrued fees, and associated yield. LP tokens serve as receipts that can be redeemed to withdraw the underlying liquidity position at any time.
