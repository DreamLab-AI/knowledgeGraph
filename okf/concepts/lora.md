# LoRa

LoRa is a long-range, low-power wireless modulation technology that uses chirp spread-spectrum signalling to transmit small amounts of data over distances of several kilometres on unlicensed sub-gigahertz radio bands. It trades data rate for range and energy efficiency, enabling battery-powered devices to operate for years. LoRa provides the physical layer beneath the LoRaWAN networking protocol used in wide-area sensor deployments. It is a foundational technology for low-power wide-area Internet-of-things connectivity.
