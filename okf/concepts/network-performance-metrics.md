# Network Performance Metrics

Network Performance Metrics are quantitative measures used to characterise the operational quality of a communication network, encompassing latency, throughput, packet loss rate, jitter, and availability. These metrics are collected continuously from network devices, links, and endpoints to support quality-of-service enforcement, capacity planning, fault detection, and SLA compliance verification. They underpin all layers of network management from physical links to application-level experience.
