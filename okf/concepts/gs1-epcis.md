# GS1 EPCIS

GS1 EPCIS (Electronic Product Code Information Services) is a global standard that defines a common data model and interface for capturing and sharing supply-chain visibility events, answering what, when, where, why, and how for product movements. It standardises event-based traceability across trading partners using GS1 identifiers. EPCIS is widely deployed in pharmaceuticals, food safety, and logistics to enable end-to-end provenance.
