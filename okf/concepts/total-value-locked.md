# Total Value Locked

Total Value Locked (TVL) is a metric that aggregates the market value of all assets deposited in a decentralised finance protocol or across an ecosystem at a given time. It serves as a proxy for adoption, liquidity depth and the economic weight of a protocol's smart contracts. Because it is denominated in volatile assets, TVL can shift with both deposit flows and underlying price movements, so it is interpreted alongside other indicators.
