# Graph Analytics

Graph Analytics is a computational discipline that applies graph-theoretic algorithms to structured relational data in order to discover patterns, measure importance, detect communities, and predict missing links. It operates on data modelled as nodes (entities) and edges (relationships), enabling analyses that are intractable with tabular data models when relationship structure is central to insight.
