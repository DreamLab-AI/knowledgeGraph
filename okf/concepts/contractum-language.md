# Contractum Language

Contractum is a high-level smart-contract programming language designed for the RGB protocol, which performs client-side validation of state transitions anchored to Bitcoin. It compiles to AluVM bytecode and lets developers express RGB schemas and contract logic in a readable, declarative form. It is central to authoring confidential, scalable contracts that settle off-chain while inheriting Bitcoin's security.
