# AI Agent Payments

AI Agent Payments refers to the infrastructure, protocols, and economic mechanisms that enable autonomous AI agents to initiate, authorise, and settle financial transactions on behalf of users or autonomously as principals, spanning micropayment rails for API service consumption, programmatic access to payment networks, and identity-bound wallet abstractions that constrain agent spending to authorised scopes and budgets.
