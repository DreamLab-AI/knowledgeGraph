# User Directory

A user directory is a centralised repository that stores and organises identity records, attributes and credentials for the principals of a system, supporting authentication and authorisation queries. Common implementations include LDAP directories, Active Directory and cloud identity stores, which identity providers consume to validate and describe users. It is a core component of identity and access management infrastructure.
