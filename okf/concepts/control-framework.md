# Control Framework

A control framework is a structured set of governance, risk, and compliance controls that an organisation adopts to manage risk and demonstrate conformance to regulatory or industry requirements. Examples include NIST CSF, COBIT, ISO 27001, and SOC 2, each mapping objectives to specific control activities and evidence. It provides a common reference for designing, operating, and auditing controls consistently.
