# Computer Vision Task

A Computer Vision Task is a specific computational problem solved using visual input data, encompassing image classification, object detection, semantic segmentation, instance segmentation, and pose estimation. These tasks form the building blocks of downstream vision applications such as scene understanding, autonomous navigation, and visual question answering, typically implemented via convolutional or transformer-based neural architectures.
