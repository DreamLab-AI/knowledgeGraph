# Propositional Logic

Propositional logic, also known as sentential logic or zeroth-order logic, is a formal system in which the basic units are whole propositions that are either true or false, combined using logical connectives such as conjunction, disjunction, negation, implication, and biconditional. It studies the truth-functional behaviour of compound statements and provides the foundation on which richer logics, including predicate logic, are built. Its decidability and clear semantics make it central to circuit design, satisfiability solving, and automated reasoning.
