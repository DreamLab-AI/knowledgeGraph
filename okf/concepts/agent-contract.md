# Agent Contract

An agent contract is an agreed set of terms that an AI agent exposes, declared as `Contract` in the contract module of the Agent Ontology.[^1] The Agent Ontology declares the class without a definition; this one follows from its properties. visionGraph places it under [[Api Contract]].
