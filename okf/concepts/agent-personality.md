# Agent Personality

An agent personality is a stable behavioural schema for an agent that shapes decision preference, risk style, response architecture and interaction patterns.[^1] visionGraph places it under [[Persona]] and as part of an [[Agent Profile]], to which it is attached by `hasPersonality`.
