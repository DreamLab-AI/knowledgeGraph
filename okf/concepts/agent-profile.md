# Agent Profile

An agent profile is a stable behavioural descriptor for an autonomous agent, covering its pragmatic and behavioural parameters.[^1] Where identity, capability, delegation and ledger describe what an agent can do, the profile describes how it behaves. visionGraph places it under [[Persona]].
