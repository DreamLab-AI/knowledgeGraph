# Request For Comments

A Request for Comments (RFC) is a formally numbered document in a series used to define, describe and discuss internet technologies, protocols, procedures and conventions. Originating with the early ARPANET community and now stewarded primarily through the IETF, RFCs range from formal standards to informational and experimental memos. The series provides a durable, citable record of how core internet infrastructure is specified and evolved.
