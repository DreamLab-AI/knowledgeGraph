# Payment Token

A Payment Token is a cryptocurrency token whose primary purpose is to serve as a medium of exchange and store of value for peer-to-peer and merchant payments, distinguished from utility tokens (access rights) and security tokens (equity/asset claims). Examples include Bitcoin, Litecoin, and CBDC-backed digital currencies.
