# Mob Programming

Mob programming is a software development practice in which the whole team works on the same task at the same time, on the same computer, rotating the roles of driver and navigators. It extends pair programming to the full group, concentrating collective knowledge to improve code quality, shorten feedback loops, and spread learning. It trades raw parallelism for higher alignment and fewer hand-offs.
