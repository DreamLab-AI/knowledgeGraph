# Security Testing

Security testing is the evaluation of software to discover vulnerabilities and verify that security controls behave as intended. It includes static application security testing, dynamic testing, dependency and secret scanning, fuzzing, and penetration testing. Integrated into development pipelines, it shifts vulnerability discovery earlier and continuously throughout the software lifecycle.
