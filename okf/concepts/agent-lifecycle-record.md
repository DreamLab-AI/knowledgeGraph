# Agent Lifecycle Record

An agent lifecycle record is the record of the lifecycle of an AI agent, declared as `LifecycleRecord` in the lifecycle module of the Agent Ontology.[^1] The Agent Ontology declares the class without a definition; this one follows from its properties. visionGraph places it under [[Lifecycle Management]].
