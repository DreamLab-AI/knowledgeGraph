# Keypoint Detection

Keypoint detection is a computer vision task that locates salient, semantically meaningful points in an image, such as body joints, facial landmarks or object corners. It outputs spatial coordinates, often with confidence scores, that can be tracked across frames or matched between views. Keypoint detection is a building block for pose estimation, image registration and structure-from-motion.
