# CNCF

The Cloud Native Computing Foundation (CNCF) is a vendor-neutral, open-source foundation established in 2015 under the Linux Foundation to steward cloud-native software projects including Kubernetes, Prometheus, Envoy, and over 150 additional hosted projects. CNCF defines cloud-native computing as building and running scalable applications in modern, dynamic environments such as public, private, and hybrid clouds using techniques including containers, microservices, and declarative APIs. The Foundation operates a Technical Oversight Committee (TOC) that governs project acceptance through sandbox, incubating, and graduated maturity stages.
