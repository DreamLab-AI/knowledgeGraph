# Ice Snow Interface

An ice snow interface is the boundary between a snow layer and the ice beneath it, treated in the retained sources as a height that altimeters try to locate.[^1][^2] NOAA's snow depth product defines it through the geometry of snow-covered sea ice, with the interface height above sea level as one of the quantities.[^1]
