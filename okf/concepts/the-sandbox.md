# The Sandbox

The Sandbox is a blockchain-based virtual world and game-creation platform where users build, own and monetise voxel-based experiences and assets recorded as non-fungible tokens on Ethereum, combining user-generated content authoring tools with a decentralised token economy centred on virtual land and in-world items.
