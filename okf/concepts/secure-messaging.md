# Secure Messaging

Secure messaging is the exchange of messages protected by cryptography so that only intended participants can read or authenticate them. It typically provides end-to-end encryption, forward secrecy, and integrity, often through ratcheting key-agreement protocols. It underpins privacy-preserving communication in consumer apps, enterprise systems, and decentralised networks.
