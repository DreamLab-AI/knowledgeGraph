# Cursor

Cursor is an AI-native code editor developed by Anysphere, built on a Visual Studio Code foundation and deeply integrated with large language models to provide inline code completion, multi-file agentic editing, natural-language chat over the codebase, and autonomous background agents. As of 2026, Cursor is the leading independent AI coding assistant by revenue, having reached $2 billion ARR and a $29.3 billion Series D valuation, and is used by over 64% of Fortune 500 companies.
