# Hugging Face Model Hub

The Hugging Face Model Hub is a public repository and platform for sharing, discovering, and versioning machine-learning models, datasets, and demo spaces. Built on Git and Git-LFS, it hosts hundreds of thousands of pretrained models with standardised model cards, metadata, and direct integration into the Transformers ecosystem. It functions as the central distribution layer for open machine-learning artefacts.
