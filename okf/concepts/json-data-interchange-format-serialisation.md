# JSON Serialisation

JSON serialisation is the process of encoding in-memory data structures into JavaScript Object Notation text and decoding that text back into structured values. It provides a human-readable, language-independent representation for objects, arrays, numbers, strings and booleans. JSON serialisation is the default interchange format for web APIs, configuration files and message-passing between heterogeneous systems.
