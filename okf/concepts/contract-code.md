# Contract Code

Contract code is the executable program logic that defines the rules, state, and behaviour of a smart contract deployed on a distributed ledger. It is typically written in a high-level language such as Solidity or Kotlin and compiled to bytecode that nodes execute deterministically. Because it is immutable once deployed and controls value, contract code is a primary target for auditing and formal verification.
