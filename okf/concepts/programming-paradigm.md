# Programming Paradigm

Programming Paradigms in AI represent fundamental styles and approaches to structuring code for artificial intelligence systems. Key paradigms include imperative (procedural, object-oriented), declarative (functional, logic-based), and differentiable programming, each shaping how models are specified, composed, and optimised across symbolic and neural approaches.
