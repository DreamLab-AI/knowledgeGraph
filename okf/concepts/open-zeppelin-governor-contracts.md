# OpenZeppelin Governor Contracts

OpenZeppelin Governor Contracts are a modular on-chain governance framework that lets DAOs run proposal, voting, and execution workflows tied to governance tokens. The Governor base contract integrates with token-based voting power (including delegation and timelock execution) and is configurable for quorum, voting periods, and vote-counting strategies. It is a widely adopted standard for implementing token-weighted decentralized governance.
