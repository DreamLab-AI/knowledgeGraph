# Encryption Protocol

An Encryption Protocol is a defined set of rules and message exchanges that uses cryptographic algorithms to establish keys and protect the confidentiality and integrity of data in transit or at rest. It specifies handshakes, cipher negotiation, key exchange, and authentication so that interoperating parties can communicate securely. TLS 1.3 is a widely deployed example securing internet traffic.
