# Embedded AI Frameworks

Software infrastructure and tooling optimised for deploying and running machine learning models on resource-constrained embedded systems and edge devices, with footprints of 100 KB to 10 MB, supporting INT8/FP16 quantisation, NPU/FPGA/DSP hardware acceleration abstraction, and streamlined memory allocation to avoid heap fragmentation on microcontrollers.
