# Figma

Figma is a browser-based collaborative interface-design and prototyping platform that lets multiple designers work simultaneously on the same files in real time. It provides vector editing, component and design-system management, interactive prototyping, and developer hand-off, all stored in the cloud for seamless multiplayer collaboration. Figma has become a standard tool for UI/UX design and cross-functional product teams.
