# Data Fabric

A data fabric is an architectural approach that provides a unified, metadata-driven layer for accessing, integrating and governing data across heterogeneous and distributed sources. It uses active metadata, knowledge graphs and automation to connect data without forcing physical consolidation. By abstracting underlying systems it delivers consistent discovery, access and governance, reducing the friction of fragmented data estates.
