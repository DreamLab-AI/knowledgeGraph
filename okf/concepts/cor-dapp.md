# CorDapp

A CorDapp (Corda Distributed Application) is a distributed application built to run on the R3 Corda enterprise blockchain platform. It bundles the contracts, states, and flows that define shared business logic and the point-to-point messaging that coordinates transactions between participating nodes. CorDapps are the unit of deployment by which enterprises implement permissioned, privacy-preserving workflows on Corda.
