# High Bandwidth Memory

High Bandwidth Memory (HBM) is a 3D-stacked DRAM technology that places multiple memory dies on a silicon interposer adjacent to a processor, delivering very wide buses and high memory bandwidth at low power per bit. It is the standard memory for AI accelerators and GPUs where feeding compute units with data is the dominant bottleneck. HBM enables training and inference of large models that would otherwise be memory-bandwidth bound.
