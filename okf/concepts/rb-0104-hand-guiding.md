# rb 0104 hand guiding

Hand guiding is a collaborative robot operation mode in which an operator physically moves the robot arm by direct physical contact, typically through a dedicated hand-guiding device, while the robot's safety systems monitor force, speed, and separation. It is one of four collaborative operation modes defined in ISO/TS 15066 and ISO 10218, enabling intuitive programming-by-demonstration and safe human-robot co-manipulation tasks.
