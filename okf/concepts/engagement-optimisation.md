# Engagement Optimisation

Engagement optimisation is the use of machine-learning models and feedback loops to maximise a user's interaction with a system, measured by signals such as session length, return frequency, and response rate. It typically learns from behavioural data to personalise content, timing, and prompts. While it can improve usefulness, it raises ethical concerns when optimisation targets attention or dependency rather than user benefit.
