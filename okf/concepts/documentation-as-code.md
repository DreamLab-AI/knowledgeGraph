# Documentation As Code

Documentation as Code is a software-engineering practice in which technical documentation is authored in plain-text markup, stored in version control alongside source code, and built and published through the same automated pipelines used for software. It applies developer workflows such as pull requests, code review, linting, and continuous integration to documentation. The approach keeps docs synchronised with code and improves consistency, traceability, and collaboration.
