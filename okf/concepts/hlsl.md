# HLSL

HLSL (High-Level Shading Language) is Microsoft's C-like programming language for writing GPU shader programs targeting the Direct3D graphics API. It lets developers author vertex, pixel, geometry, and compute shaders that run on the programmable stages of the rendering pipeline. HLSL is a cornerstone of real-time graphics on Windows and Xbox platforms.
