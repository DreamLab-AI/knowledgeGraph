# VRM Format

An open file format standard for 3D humanoid avatars built on glTF, designed for cross-platform interoperability in VR, AR, and metaverse applications. It incorporates standardised humanoid rigging, facial blend-shape expressions, first-person gaze controls, and embedded licensing metadata, enabling seamless avatar portability across different virtual environments. In 2024 the VRM Consortium began collaboration with the Khronos Group to advance VRM specifications as official glTF extensions for international standardisation.
