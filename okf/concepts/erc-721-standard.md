# ERC-721 Standard

ERC-721 is an Ethereum token standard defining a minimal interface for non-fungible tokens (NFTs), where each token carries a unique identifier that distinguishes it from every other token in the same contract. It specifies ownership tracking, safe transfer functions, and an optional metadata extension for associating URIs with token properties.
