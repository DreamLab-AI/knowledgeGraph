# MultiAccessEdgeComputing

Multi-Access Edge Computing (MEC) is an ETSI-standardised architecture that places cloud-like compute and storage resources at the radio access network edge, enabling low-latency application hosting within milliseconds of end-user devices. It decouples latency-sensitive processing from centralised cloud data centres by co-locating compute with base stations and other network nodes.
