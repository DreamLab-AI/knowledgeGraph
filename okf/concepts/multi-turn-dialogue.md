# Multi-Turn Dialogue

Multi-turn dialogue is a conversational interaction spanning several exchanges in which a system must maintain context, track state, and resolve references across turns to produce coherent, relevant responses. It contrasts with single-turn question answering by requiring memory of prior utterances and the evolving goal. It is a core capability and evaluation axis for chatbots and conversational AI.
