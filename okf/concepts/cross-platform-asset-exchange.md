# Cross-Platform Asset Exchange

Cross-platform asset exchange is the capability to move 3D models, textures, and other digital assets between different metaverse platforms, engines, and tools while preserving fidelity and usability. It depends on shared 3D file formats and import/export pipelines that map assets onto each platform's runtime. It is a prerequisite for interoperable virtual worlds and portable user content.
