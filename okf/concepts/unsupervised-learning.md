# Unsupervised Learning

Unsupervised Learning discovers hidden patterns, structures, and representations in unlabeled data without explicit supervision. Key techniques include clustering, dimensionality reduction, density estimation, anomaly detection, and generative modelling, enabling exploratory data analysis and latent feature extraction.
