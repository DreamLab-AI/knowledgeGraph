# Project Agora

Project Agora is a cross-border wholesale payments initiative led by the Bank for International Settlements with several central banks and private financial institutions. It explores integrating tokenised commercial-bank deposits with tokenised central-bank money on a unified programmable ledger to improve cross-border settlement. It is a flagship experiment in the tokenisation of the monetary and financial system.
