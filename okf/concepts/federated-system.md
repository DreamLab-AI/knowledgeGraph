# Federated System

A federated system is a distributed architecture composed of autonomous, independently operated nodes or servers that cooperate under shared protocols while retaining local control over their own data and policies. Unlike fully centralised systems, federation distributes authority across multiple operators, and unlike fully decentralised peer-to-peer networks, it relies on a finite set of identifiable, semi-trusted servers. This model underpins federated social networks, messaging, and consortium-style trust arrangements.
