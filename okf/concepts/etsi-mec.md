# ETSI MEC

ETSI MEC (Multi-access Edge Computing) is a set of standards from the European Telecommunications Standards Institute defining an open framework for running applications at the edge of mobile and fixed networks, close to end users. It specifies APIs and a reference architecture so applications can access low-latency compute, radio-network information, and location services hosted at base stations or aggregation points. MEC is foundational to latency-sensitive use cases such as AR, autonomous systems, and IoT.
