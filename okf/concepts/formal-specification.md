# Formal Specification

A formal specification is a precise, mathematically grounded description of the intended behaviour or structure of a system, written in a language with well-defined syntax and semantics. It allows properties of the system to be stated unambiguously and reasoned about or verified mechanically. Formal specifications underpin formal methods, model checking, and the construction of provably correct software and ontologies.
