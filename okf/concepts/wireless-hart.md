# WirelessHART

WirelessHART is an open wireless communication standard for industrial process automation, built on the IEEE 802.15.4 physical layer and using time-synchronised, self-organising mesh networking with channel hopping for reliability. It extends the HART field-device protocol to wireless sensor networks in plants, providing deterministic, secure, low-power monitoring and control. Centrally managed by a network manager, it prioritises robustness against interference in harsh RF environments.
