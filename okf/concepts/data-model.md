# Data Model

A data model is an abstract specification of how data elements are structured, related and constrained within a domain or system. It defines entities, attributes, relationships and integrity rules at conceptual, logical or physical levels of abstraction. Data models are prerequisites for metadata standards and for designing storage, exchange and querying of data.
