# Curve25519

Curve25519 is a Montgomery-form elliptic curve designed for fast, secure elliptic-curve Diffie-Hellman key exchange at a 128-bit security level. It was engineered to avoid common implementation pitfalls by enabling constant-time, branch-free arithmetic and to sidestep concerns about opaque parameter selection through rigid, transparent design choices. It underpins the X25519 key-agreement function and is widely deployed in modern secure-transport and messaging protocols.
