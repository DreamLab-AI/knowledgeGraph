# Satellite-based Augmentation System

A satellite-based augmentation system, or SBAS, is a regional overlay that improves an underlying GNSS. Reference stations at surveyed locations observe satellite, clock and propagation errors; processing centres calculate corrections and integrity information; geostationary satellites then broadcast the messages to compatible receivers.[^1]
