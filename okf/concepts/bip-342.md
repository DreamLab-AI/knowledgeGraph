# BIP-342

BIP-342 specifies Tapscript, the updated Bitcoin scripting language that replaces legacy script in the script-path spending branch of Taproot (BIP-341) outputs. Tapscript updates the signature opcodes to use BIP-340 Schnorr signatures, introduces the OP_CHECKSIGADD opcode to enable efficient threshold multisignature constructions, relaxes script resource limits, and establishes an extensible opcode upgrade mechanism via OP_SUCCESS opcodes for future soft forks.
