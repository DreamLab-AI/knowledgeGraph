# Model Versioning

Model versioning is the practice of tracking and managing successive versions of machine learning models, recording the code, data, hyperparameters, and checkpoints that produced each one. It enables reproducibility, rollback, lineage tracing, and controlled promotion of models through development and production stages. Model registries and artefact stores implement versioning as a core MLOps capability.
