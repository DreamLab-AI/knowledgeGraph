# Single Window

A single window is a facility that allows parties involved in trade and transport to lodge standardised information and documents at a single entry point to fulfil all import, export and transit-related regulatory requirements, with each data element submitted only once electronically; this is the definition of UN/CEFACT Recommendation No. 33.[^1]
