# WebXR

WebXR is a W3C web standard and browser API that enables access to virtual reality and augmented reality hardware, exposing device pose tracking, controller input, reference spaces, and an XR-integrated render loop so that immersive spatial experiences can be delivered through ordinary URLs without native installation.
