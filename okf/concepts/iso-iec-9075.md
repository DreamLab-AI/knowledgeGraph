# ISO/IEC 9075 SQL Standard

ISO/IEC 9075 is the international standard that defines SQL, the Structured Query Language used to define, query and manipulate data in relational database systems. Published jointly by ISO and IEC and revised across multiple editions, it specifies the language's data model, syntax, semantics and conformance levels through a series of parts covering the core framework, foundation, call-level interface and extensions such as JSON and property-graph queries. It provides the common reference that lets relational databases interoperate and that vendors extend with proprietary dialects.
