# ShEx

ShEx (Shape Expressions) is a language for describing and validating the structure of RDF graphs, specifying which properties a node must have, their cardinalities, and value constraints. It serves a role for linked data analogous to schemas for XML or JSON, enabling data producers and consumers to agree on graph shapes. It is widely used to validate Solid pods and Wikidata-style knowledge graphs.
