# Coordinate Reference System

A coordinate reference system (CRS) is a framework that defines how positions are described and measured on or near the Earth's surface, combining a datum, a coordinate system, and often a map projection. It enables consistent interpretation of spatial coordinates by anchoring them to a known model of the Earth. CRSs are essential for aligning geospatial data sets and for accurate location computations.
