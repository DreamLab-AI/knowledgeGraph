# Scorm

SCORM (Sharable Content Object Reference Model) is a set of technical standards for packaging and exchanging e-learning content so that courses run consistently across compliant learning management systems. It defines content packaging, run-time communication and sequencing so that a course can report completion, scores and time to the host platform. SCORM established interoperability for digital learning content and is a predecessor to xAPI.
