# Compiler

A software system that translates source code written in a high-level programming language into a lower-level representation — typically machine code, bytecode, or an intermediate representation — performing lexical analysis, syntactic parsing, semantic checking, optimisation, and code emission in a structured pipeline. Compilers are foundational to software development, enabling human-readable programs to run efficiently on hardware.
