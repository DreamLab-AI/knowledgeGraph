# Image Sensor

An image sensor is a solid-state device that converts incident light into electrical signals to capture a digital image, typically implemented as a CMOS or CCD array of photodetector pixels. Each pixel accumulates charge proportional to received photons, which is read out, digitised, and assembled into a frame. Image sensors are the core capture element in cameras and many computer-vision and tracking systems.
