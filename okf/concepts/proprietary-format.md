# Proprietary Format

A proprietary format is a data or file format whose specification is controlled by a single vendor and is not openly published or freely implementable. Access to and interpretation of the data typically depend on the vendor's software, which can constrain interoperability, archival longevity, and user control. Proprietary formats stand in contrast to open standards and are a common source of vendor lock-in.
