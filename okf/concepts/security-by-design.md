# Security By Design

Security by design is an engineering approach in which security is treated as a foundational requirement and built into systems from the earliest stages rather than bolted on retrospectively. It favours secure defaults, minimal attack surface, defence in depth and least-privilege access, supported by threat modelling and continuous verification across the development lifecycle. The principle is increasingly mandated by regulators and procurement frameworks for connected products and critical infrastructure.
