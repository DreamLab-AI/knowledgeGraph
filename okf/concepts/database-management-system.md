# Database Management System

A database management system (DBMS) is software that defines, stores, retrieves, secures and manages structured data while enforcing integrity, concurrency and durability. It mediates all access to the underlying database through a query interface and transaction manager, supporting models such as relational, document, key-value and graph. It is the foundational platform for persistent data services including ontology repositories and taxonomy registries.
