# Virtual World Operation

Virtual world operation is the ongoing technical and administrative running of a persistent virtual environment, including server orchestration, state synchronisation, content updates, moderation and economy management. It keeps the world available, consistent and safe for concurrent users across sessions. Operation is the runtime layer that realises the design encoded in a metaverse architecture or stack.
