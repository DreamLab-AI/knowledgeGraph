# Linked Open Data

Linked Open Data is the practice of publishing structured data on the web under open licences using Linked Data principles, RDF and dereferenceable URIs so that datasets can be interlinked and queried across sources. It forms a global web of data, complementary to the web of documents, in which entities reference one another across organisational boundaries. Reference datasets such as DBpedia and Wikidata are central hubs, and Berners-Lee's five-star scheme rates the openness and linkage of published data.
