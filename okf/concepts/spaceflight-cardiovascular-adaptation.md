# Spaceflight Cardiovascular Adaptation

Spaceflight cardiovascular adaptation is the set of changes in heart and blood vessel function that occur in microgravity, with acute responses that include raised preload and stroke volume and chronic changes that include cardiac atrophy, vascular remodelling and autonomic impairment.[^1]
