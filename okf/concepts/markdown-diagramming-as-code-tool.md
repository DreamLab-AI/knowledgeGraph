# Markdown Diagramming As Code Tool

A JavaScript-based diagramming-as-code tool that renders flowcharts, sequence diagrams, Gantt charts, entity-relationship diagrams, and other diagram types from plain-text markup embedded in Markdown documents. Mermaid is widely adopted in developer documentation workflows, enabling version-controllable, maintainable diagrams without external tooling. It integrates natively with platforms such as GitHub, GitLab, Notion, and Logseq.
