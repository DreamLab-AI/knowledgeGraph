# RFID

Radio-Frequency Identification (RFID) is a wireless technology that uses electromagnetic fields to automatically identify and track tags attached to objects. Tags contain electronically stored information and can be read without requiring line of sight, enabling automated data capture across distances from a few centimetres to several metres.
