# Protocol

A protocol is an agreed set of rules and message formats that govern how two or more parties exchange information or coordinate behaviour. It defines the syntax, semantics, timing and error handling needed for systems to interoperate reliably without prior bespoke arrangement. Protocols underpin networking, distributed systems and many forms of machine-to-machine and human-to-machine interaction.
