# Display and Rendering

Taxonomy hub for display and rendering technologies within spatial computing, encompassing the pipelines, hardware, and algorithms that transform scene geometry into visual output for AR, VR, and mixed reality experiences. This category bridges hardware display devices with software rendering techniques, covering both real-time and offline methods optimised for immersive perceptual fidelity.
