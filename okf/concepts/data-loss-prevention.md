# Data Loss Prevention

Data loss prevention (DLP) is a set of security controls and technologies that detect and block the unauthorised exfiltration, leakage or misuse of sensitive data. DLP systems classify content, monitor data in use, in motion and at rest, and enforce policies at endpoints, networks and cloud services. It is a core data-protection capability supporting compliance with privacy and confidentiality requirements.
