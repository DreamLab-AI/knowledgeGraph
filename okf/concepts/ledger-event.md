# Ledger Event

A ledger event is the canonical semantic event in an append-only ledger stream, declared in the Agent Ontology as `LedgerEvent`.[^1] It has two declared subclasses, the [[Runtime Ledger Event]] and the [[Governance Ledger Event]]. visionGraph places it under [[Event]] and as a part of a [[Ledger]].
