# Open Bridge Standard

An Open Bridge Standard is a publicly specified protocol for transferring assets and messages between independent blockchains in an interoperable, vendor-neutral way. It defines common formats for lock/mint, burn/release, and message-passing operations so that distinct bridge implementations can interoperate and be audited against shared security assumptions. Such standards aim to reduce fragmentation and the systemic risk associated with bespoke cross-chain bridges.
