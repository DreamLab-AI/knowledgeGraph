# Language Preference

A language preference is a set of linguistic parameters that govern how an agent expresses and parses language. In the SAC-CG Agent Ontology the class `LanguagePreference` is defined as covering "preferred language, register, clarity constraints, or structural tendencies affecting expression and parsing".[^1]
