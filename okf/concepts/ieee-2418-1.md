# IEEE 2418.1

IEEE 2418.1 is the IEEE Standard for the Framework of Blockchain Use in Internet of Things (IoT), establishing a common vocabulary, reference architecture, and conceptual building blocks for integrating distributed ledger technology with IoT systems. It specifies the relationship between blockchain components and IoT devices, defines trust and security requirements for IoT data provenance, and provides a foundation for interoperability across heterogeneous IoT deployments. The standard addresses data integrity, device identity, and transactional automation through smart contracts within constrained IoT environments.
