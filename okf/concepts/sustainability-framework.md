# Sustainability Framework

A sustainability framework is a structured set of principles, metrics, and reporting standards used to measure and manage the environmental, social, and governance impact of an organisation or system. It defines what to measure, how to compute indicators such as carbon footprint, and how to disclose results so that performance can be compared and audited. Frameworks like GHG Protocol and emerging crypto-specific schemes provide the methodological backbone for sustainability claims.
