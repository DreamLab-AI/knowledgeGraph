# Matrix Protocol

Matrix is an open standard and communication protocol for real-time, decentralised communication over the internet. It enables interoperable, federated messaging and collaboration by allowing servers from different organisations to synchronise shared conversation state. The protocol supports end-to-end encryption, persistent history, and a rich ecosystem of clients and bridges.
