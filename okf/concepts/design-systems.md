# Design Systems

A design system is a single source of truth that combines reusable UI components, design tokens, patterns, and documentation governing how a product looks and behaves. It unifies designers and engineers around a shared component library and usage guidelines, ensuring consistency and accelerating delivery across teams and platforms. It encompasses both the visual language and the coded implementation that enforces it.
