# Reinforcement Learning Algorithm

Reinforcement Learning Algorithms enable agents to learn optimal decision-making policies through interaction with environments, guided by reward signals. Core families include value-based methods (Q-learning, DQN), policy gradient methods (REINFORCE, PPO, TRPO), and actor-critic approaches (A3C, SAC), all of which balance exploration against exploitation to maximise cumulative expected reward.
