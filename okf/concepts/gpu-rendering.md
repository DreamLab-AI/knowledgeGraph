# GPU Rendering

GPU rendering is the computation of images from 2D or 3D scene descriptions using the massively parallel processing units of a graphics processing unit rather than the CPU. By executing shading, rasterisation, and ray-tracing workloads across thousands of cores, it delivers real-time interactive graphics and accelerates offline rendering. It is foundational to game engines, visualisation, and digital-content creation tools.
