# OpenZeppelin Contracts

OpenZeppelin Contracts is a widely used open-source library of secure, audited, and reusable smart-contract components for Ethereum and EVM-compatible chains. It provides standard implementations of token interfaces such as ERC-20, ERC-721, and ERC-1155, along with access control, upgradeability, and security utilities. The library is a de facto baseline for safe smart-contract development, reducing the risk of common vulnerabilities.
