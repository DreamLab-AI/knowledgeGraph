# Reference Model

A reference model is an abstract, authoritative description of the desired behaviour or structure of a system, used as the standard against which an actual implementation is measured or controlled. In control theory it specifies the ideal closed-loop response that a model-reference adaptive controller drives the plant to follow. In evaluation it serves as the baseline whose outputs define the expected target.
