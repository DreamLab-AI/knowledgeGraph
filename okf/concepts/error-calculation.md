# Error Calculation

Error calculation is the step in a control system that computes the difference between a desired setpoint and the measured process variable. This error term is the input that drives corrective action in feedback controllers such as PID loops. Accurate, low-latency error calculation is essential for stable and responsive position, velocity, and other regulated control behaviours.
