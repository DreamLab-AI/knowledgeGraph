# ROS REP

A ROS Enhancement Proposal (REP) is a design document that defines conventions and standards for the Robot Operating System ecosystem, analogous to internet RFCs or Python PEPs. REPs codify agreements such as coordinate-frame conventions, units, naming, and message interfaces so that independently developed robotics components interoperate. They provide the normative reference that aligns platforms and libraries.
