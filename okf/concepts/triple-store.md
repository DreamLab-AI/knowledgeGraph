# Triple Store

A triple store is a database purpose-built to store and query RDF data as subject-predicate-object triples, forming the storage layer for semantic-web and knowledge-graph applications. It supports the SPARQL query language and often provides reasoning and inference over ontologies, enabling expressive graph traversal and entailment beyond what relational stores offer.
