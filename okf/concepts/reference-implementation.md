# Reference Implementation

A reference implementation is an authoritative, openly available realisation of a specification or standard that demonstrates how it is meant to be built and used. It serves as a concrete benchmark against which other implementations can be compared for correctness and conformance. By turning a written specification into working software, it reduces ambiguity and accelerates adoption of the standard.
