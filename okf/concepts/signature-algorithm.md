# Signature Algorithm

A signature algorithm is a cryptographic scheme comprising key generation, signing, and verification procedures that lets a holder of a private key produce a value provably tied to a message, which anyone with the public key can verify. It provides authenticity, integrity, and non-repudiation, with families including RSA, ECDSA, EdDSA, and Schnorr. It is the cryptographic primitive underpinning digital signatures.
