# Issue Tracking

Issue tracking is the practice and supporting tooling for recording, prioritising, assigning, and resolving units of work such as bugs, feature requests, and tasks across a software project. Each issue carries metadata, status, discussion, and links to code changes, giving teams a shared backlog and an audit trail of decisions. It underpins collaborative and agile development and integrates tightly with version control and continuous integration.
