# Inter-satellite Link

An inter-satellite link is a direct communication path between spacecraft. It may use an optical carrier or a radio-frequency band, and it can connect satellites in the same orbital regime or bridge different orbits. The term describes the physical link; routing, storage and delivery to an end user belong to the wider network.
