# Format Compliance

Format compliance is the property of a digital asset or file conforming exactly to the structural, encoding, and schema rules of a defined file or data format specification. Verifying compliance ensures that assets can be reliably parsed, exchanged, and rendered by conformant tools across the supply chain. It is a precondition for interoperability between content producers and consumers.
