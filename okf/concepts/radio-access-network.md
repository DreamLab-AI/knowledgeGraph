# Radio Access Network

A radio access network (RAN) is the part of a mobile telecommunications system that connects user devices to the core network over the air interface via base stations and antennas. It manages radio resource allocation, modulation, and handover across cells. Modern architectures such as Open RAN disaggregate hardware and software to enable multi-vendor, virtualised deployments.
