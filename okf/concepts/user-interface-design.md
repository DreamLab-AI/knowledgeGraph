# User Interface Design

User interface design is the discipline of shaping the visual and interactive surfaces through which people operate digital products, determining layout, controls, typography, colour and feedback. It translates user goals and information structure into coherent, learnable and aesthetically consistent screens and interactions. As a sibling of interaction design and a contributor to overall user experience, it balances usability, accessibility and brand expression.
