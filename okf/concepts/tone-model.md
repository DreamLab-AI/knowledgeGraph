# Tone Model

A tone model is a pragmatic modulation model that guides an agent's emotional stance and manner of interaction. In the SAC-CG Agent Ontology the class `ToneModel` is defined as guiding "emotional stance, pacing, softness/firmness, or collaborative rhythm".[^1]
