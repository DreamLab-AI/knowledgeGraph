# Turing Machine

A Turing machine is an abstract model of computation consisting of an infinite tape, a read-write head, a finite set of states and a transition function that, given the current state and the symbol under the head, prescribes a symbol to write, a direction to move and a next state. Introduced by Alan Turing, it formalises the notion of an effective procedure and serves as the canonical definition of what is computable. The Church-Turing thesis holds that any function computable by any reasonable mechanism is computable by a Turing machine.
