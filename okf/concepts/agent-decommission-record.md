# Agent Decommission Record

An agent decommission record is the record of an agent's retirement from service, declared as `DecommissionRecord` in the lifecycle module of the Agent Ontology.[^1] The Agent Ontology declares the class without a definition; this one follows from its position. visionGraph places it under [[Lifecycle Management]] and as part of an [[Agent Lifecycle Record]].
