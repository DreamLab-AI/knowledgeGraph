# Agent Interface Specification

An agent interface specification is a declaration of an interface through which an agent integrates with its surrounding system, declared as `InterfaceSpec` in the agent module of the Agent Ontology.[^1] The Agent Ontology declares the class without a definition; this one follows from its use. visionGraph places it under [[Specification]] and relates it to [[Interface]].
