# International Terrestrial Reference System

The International Terrestrial Reference System (ITRS) is the Earth-fixed geocentric reference system that the International Earth Rotation and Reference Systems Service defines, realises and promotes, adopted by the International Union of Geodesy and Geophysics in 2007.[^1]
