# Ecmascript

ECMAScript is the standardised specification of the scripting language commonly implemented as JavaScript, defining its syntax, semantics, and core libraries. Maintained by Ecma International as the ECMA-262 standard and developed through the TC39 process, it provides a stable, versioned contract that browser and runtime vendors implement. ECMAScript underpins client-side web programming and a large ecosystem of server-side and tooling runtimes.
