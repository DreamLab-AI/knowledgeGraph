# Cooperative Game Theory

Cooperative game theory is the branch of game theory that studies how groups of agents can form coalitions and how the value they jointly create should be divided among members. Rather than focusing on individual strategies, it analyses solution concepts such as the core and the Shapley value that capture fair or stable allocations of collective payoff. Its allocation principles underpin applications from economics and mechanism design to feature attribution in explainable machine learning.
