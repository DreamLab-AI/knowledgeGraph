# Upper Ontology

An upper ontology, also called a foundational or top-level ontology, defines very general categories such as object, process, quality and relation that are common across all subject domains. It provides a shared semantic backbone onto which domain ontologies can be aligned, improving interoperability, reuse and reasoning. By committing to clear distinctions such as endurants versus perdurants, it grounds more specific vocabularies in a consistent conceptual framework.
