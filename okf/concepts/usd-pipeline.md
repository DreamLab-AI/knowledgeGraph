# USD Pipeline

A USD pipeline is a content production workflow built around Pixar's Universal Scene Description (USD) format, which composes, layers and exchanges complex 3D scene data across digital-content-creation tools. USD enables non-destructive collaboration through composition arcs, variants and references, making it the interchange backbone for film, games and metaverse asset production. It standardises how geometry, materials, animation and motion-capture data flow between applications.
