# Pulse-Code Modulation

Pulse-code modulation (PCM) is a method for digitally representing sampled analogue signals by periodically measuring amplitude and quantising each sample to a fixed number of bits. It is the baseline uncompressed digital audio format underlying most audio signal processing pipelines and audio systems, from which compressed codecs are derived. Its two key parameters, sample rate and bit depth, jointly determine the fidelity and file size of the represented signal.
