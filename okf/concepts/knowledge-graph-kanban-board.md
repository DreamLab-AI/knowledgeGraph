# Knowledge Graph Kanban Board

A Kanban-style project planning board within a Logseq knowledge graph that aggregates query-driven progress views across active projects. It uses embedded block queries to surface tasks tagged with progress properties, enabling at-a-glance visibility of TODO, DOING, and DONE states across linked project pages such as PlayerTwo and ParentsGuideToAI.
