# Real-Time Rendering Engine

A real-time rendering engine generates images from 3D scene descriptions fast enough to sustain interactive frame rates, typically 30 to 120+ frames per second. It coordinates GPU rasterisation or ray tracing, shading, lighting, and post-processing within a fixed per-frame time budget. It is the visual core of game engines, virtual production, and immersive metaverse experiences.
