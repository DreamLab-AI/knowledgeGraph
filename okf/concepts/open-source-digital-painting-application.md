# Open Source Digital Painting Application

Krita is a free, open-source professional digital painting and raster graphics application developed by the KDE community. It supports illustration, concept art, texture painting, and AI-assisted image synthesis via plugins such as krita-ai-diffusion, which integrates Stable Diffusion through a ComfyUI backend on a local or remote inference server.
