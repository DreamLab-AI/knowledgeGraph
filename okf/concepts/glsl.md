# GLSL

GLSL (OpenGL Shading Language) is a high-level C-like programming language for writing shaders that execute on the GPU within the OpenGL and WebGL graphics pipelines. It lets developers program the programmable stages, principally vertex and fragment shaders, to control geometry transformation, lighting, and per-pixel colour. GLSL is a foundational tool for real-time rendering and visual effects.
