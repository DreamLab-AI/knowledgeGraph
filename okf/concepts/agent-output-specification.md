# Agent Output Specification

An agent output specification describes what an agent produces as output, declared as `OutputSpec` in the agent module of the Agent Ontology.[^1] The Agent Ontology declares the class without a definition; this one follows from its position. visionGraph places it under [[Data Schema]] and as part of an [[Agent Operational Profile]], which reaches it through `output`.
