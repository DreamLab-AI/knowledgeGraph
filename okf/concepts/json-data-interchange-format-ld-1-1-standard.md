# JSON-LD 1.1 Standard

JSON-LD 1.1 is a W3C Recommendation defining a JSON-based serialization for Linked Data, allowing JSON documents to be interpreted as RDF graphs. It introduces a context mechanism that maps JSON keys to IRIs, plus features such as framing, nested contexts and typed values added in the 1.1 revision. It is the dominant format for embedding machine-readable semantics in web data.
