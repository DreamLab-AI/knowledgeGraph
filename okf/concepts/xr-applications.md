# XR Applications

XR Applications are software systems designed to run on extended reality platforms — encompassing augmented reality (AR), virtual reality (VR), and mixed reality (MR) — that blend real and virtual environments to deliver spatially aware, immersive user experiences. They span consumer entertainment, enterprise training, industrial maintenance, medical simulation, and remote collaboration domains.
