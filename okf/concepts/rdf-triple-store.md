# RDF Triple Store

An RDF triple store is a purpose-built database for storing and querying data as subject-predicate-object triples following the Resource Description Framework model. It supports the SPARQL query language and often provides reasoning over ontologies to infer implicit facts. Triple stores are the backbone of semantic-web, knowledge-graph, and linked-data applications.
