# Skeletal Mesh

A skeletal mesh is a 3D character or object model bound to an underlying bone hierarchy, or skeleton, so that mesh vertices deform smoothly as the skeleton is posed or animated. It is the standard representation for animatable characters in avatar systems and real-time engines, and it underlies procedural animation techniques that manipulate bone transforms algorithmically at runtime. Building one requires prior UV unwrapping and rigging work on the base mesh.
