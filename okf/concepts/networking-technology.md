# Networking Technology

The protocols, hardware, and software frameworks that enable real-time data transmission, synchronisation, and communication between distributed participants. In spatial computing contexts this encompasses WebRTC, QUIC, UDP/TCP stacks, adaptive bitrate streaming, and delta-compression techniques that support low-latency avatar synchronisation and shared world-state updates.
