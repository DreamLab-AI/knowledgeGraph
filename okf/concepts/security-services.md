# Security Services

Security Services are the technical and organisational mechanisms that protect spatial computing platforms from unauthorised access, data breaches, and malicious activity. They encompass authentication, encryption, access control, and identity management components that collectively enforce security policies across metaverse, cloud, and immersive technology deployments.
