# Arkit

ARKit is Apple's augmented reality development framework for iOS and iPadOS devices, providing motion tracking, environment understanding and rendering integration for placing virtual content in the physical world. It uses visual-inertial odometry, plane detection and scene reconstruction to anchor digital objects stably relative to real surfaces. ARKit gives developers a high-level API over the device camera, motion sensors and Neural Engine to build mobile AR experiences.
