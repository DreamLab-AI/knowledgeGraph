# EU Union Customs Code

The EU Union Customs Code (UCC) is the legal framework governing customs rules and procedures for goods entering, leaving, or moving within the European Union. It standardises declarations, tariff classification, valuation, origin rules, and the move toward fully electronic, paperless customs processing. The UCC is the reference regime for customs and trade-facilitation systems operating across the EU single market.
