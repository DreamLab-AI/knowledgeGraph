# Objective

A formal specification of the goal or criterion that an AI system, optimisation algorithm, or training procedure is designed to satisfy or maximise. In machine learning this is typically expressed as a loss function or reward signal that guides parameter updates; in planning and reinforcement learning it encodes desired agent behaviour through utility or reward functions.
