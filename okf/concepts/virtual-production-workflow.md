# Virtual Production Workflow

The end-to-end process for creating film and television content using virtual production techniques, integrating pre-visualisation, virtual art department asset creation, real-time game engine rendering, LED volume shooting, and post-production refinement in a non-linear pipeline where VFX work begins in pre-production rather than post-production. This approach captures composited digital environments in-camera, enabling creative decisions about lighting and framing to be made on set.
