# Agent Intent

An agent intent is a semantic expression of purpose, objective or expected action outcome.[^1] The intent module reads it as a statement of what an agent aims to achieve,[^2] and the threat-model module as a purpose or goal communicated by an agent, which is the basis of the intent-ambiguity threat.[^3] visionGraph places it under [[Goal]].
