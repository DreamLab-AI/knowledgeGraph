# Model Ensembling

A machine learning technique that aggregates predictions from multiple independently trained base models — via voting, averaging, stacking, or boosting — to reduce variance, improve generalisation, and produce more reliable outputs than any single constituent model. Diversity among base learners is the key driver of ensemble benefit.
