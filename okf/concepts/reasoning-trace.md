# Reasoning Trace

A reasoning trace is the recorded sequence of intermediate thoughts, tool calls, and decisions a model produces while solving a task, distinct from its final output. It serves as both a working scratchpad that improves accuracy and an audit artefact for inspecting how an agent reached a conclusion. Traces underpin debugging, evaluation, and self-correction in agentic systems.
