# Deflationary Token

A Deflationary Token is a cryptocurrency or blockchain token whose total circulating supply decreases over time through one or more programmatic burning mechanisms—such as transaction fee burns, scheduled buyback-and-burn events, or protocol-level token destruction—creating supply-side scarcity intended to exert upward price pressure and incentivise long-term holding.
