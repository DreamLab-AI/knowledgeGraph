# RAIN RFID Tag

A RAIN RFID tag is a passive ultra-high-frequency radio tag that uses the ISO/IEC 18000-63 air interface protocol, also known as GS1 UHF Gen2, and can carry an Electronic Product Code that identifies the item it is attached to.[^1][^2]
