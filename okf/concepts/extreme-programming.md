# Extreme Programming

Extreme Programming (XP) is an agile software-development methodology that emphasises short iterations, continuous feedback, and engineering discipline to deliver high-quality software responsive to changing requirements. Its core practices include test-driven development, pair programming, continuous integration, collective code ownership, and frequent small releases. XP treats good practices to an 'extreme' degree, for example applying continuous code review through constant pairing.
