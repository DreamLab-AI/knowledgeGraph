# Tool Registry

A tool registry is a catalogue that stores the definitions, schemas, permissions, and metadata of the external tools and functions an AI agent can invoke. It enables agents to discover, validate, and route calls to available capabilities at runtime, providing a governed and extensible interface between language models and the systems they act upon.
