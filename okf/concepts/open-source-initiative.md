# Open Source Initiative

The Open Source Initiative is a non-profit organisation that stewards the Open Source Definition and maintains the authoritative process for reviewing and approving software licences as conforming to it. By certifying which licences qualify as open source, it provides a stable, community-recognised standard that distinguishes genuine open-source terms from merely source-available ones. The organisation also advocates for open-source software and educates on licensing and policy.
