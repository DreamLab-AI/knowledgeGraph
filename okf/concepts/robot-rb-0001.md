# Robot RB-0001

Robot RB-0001 is an identifier-class for a reference mobile-manipulator robot platform that combines a mobile base with an articulated manipulator arm. As a composite robot, it integrates locomotion and manipulation subsystems so the system can both navigate an environment and perform physical tasks within it. It serves as a canonical example linking mobile-robot and manipulator capabilities.
