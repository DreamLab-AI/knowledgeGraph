A pushbroom scanner is an along-track multispectral scanner in which the motion of a detector array builds up an image as the platform moves forward.[^1]

Natural Resources Canada explains that along-track scanners use the forward motion of the platform to record successive scan lines, building a two-dimensional image perpendicular to the flight direction. The name comes from the analogy between the moving detector array and the bristles of a broom being pushed along a floor.[^1]

In the tutorial, linear-array systems are contrasted with across-track mirror scanners. It states that the array lets each detector measure a ground resolution cell for a longer dwell time, which improves radiometric resolution, and that solid-state detectors with no moving parts are smaller, lighter and more reliable. It also states that cross-calibrating thousands of detectors to a uniform sensitivity is necessary and complicated.[^1]

This page rests on one general tutorial from a single publisher. It does not name particular instruments or give performance figures, and a pushbroom design should not be assumed to apply to every spaceborne imager.

[^1]: Natural Resources Canada, “Multispectral Scanning”, Fundamentals of Remote Sensing tutorial. https://natural-resources.canada.ca/maps-tools-publications/satellite-elevation-air-photos/multispectral-scanning
