Federated Edge Learning combines distributed machine learning with edge computing, enabling collaborative model training across decentralised edge devices while keeping training data locally on-device. Participants train local models on their private datasets and securely aggregate only model updates—rather than raw data—into a shared global model, preserving data sovereignty whilst enabling collective intelligence.
