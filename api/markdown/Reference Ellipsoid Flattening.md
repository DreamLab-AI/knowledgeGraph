Reference ellipsoid flattening is the ratio of the difference between the semi-major and semi-minor axes of an ellipsoid to the semi-major axis.[^1]

According to the OGC standard, inverse flattening, also called reciprocal flattening, is sometimes given instead.[^1] An ellipsoid can be defined by its semi-major axis together with flattening or the semi-minor axis, or a spherical model can be specified.[^1]

Flattening is one of the parameters that define the ellipsoid’s shape, which in turn affects how coordinates and heights relate to the geoid.[^1][^2] Because the ratio is formed from two lengths, it carries no unit.

These sources do not give numerical flattening values for particular ellipsoids, so this page states none.
