Frame reference epoch is the epoch of coordinates that define a dynamic reference frame.[^1]

The OGC specification describes it as the epoch at which the frame's station coordinates and velocities are defined, and as a choice made in the solution's data processing. It is not necessarily the year in the name of the realisation, which the specification says mainly indicates the sequence of realisations.[^1]

It is a different quantity from the coordinate epoch, which qualifies a particular set of coordinates. A coordinate set can be given at one epoch while the frame it refers to keeps its own frame reference epoch, and the specification gives worked examples of the two being stated separately.[^1]

Frame solutions publish parameters at stated epochs. The ITRF2020 page defines zero translation and rotation parameters relative to earlier solutions at an epoch, but it does not describe this as a frame reference epoch in the OGC sense, so the link between the two usages is not asserted here.[^2]
