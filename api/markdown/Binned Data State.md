A binned data state is the processing state of data to which a binning process has been applied, so that observations are accumulated into the cells of a regular grid.[^1][^2]

SWEET defines Binned as a subclass of DataState restricted to data that had some Binning process.[^1] For ocean colour, NASA describes Level-3 binned data products as the accumulated data for all Level-2 data over a period of one day, 8 days, a calendar month or a calendar year.[^2] NASA's processing levels describe Level 3A data as generally periodic summaries of Level 2 products.[^3]

Standard mapped image products are described as image representations of binned data products, so mapping is a later step than binning.[^2] The retained sources do not establish a binning scheme common to all sensors, and the binned examples come from ocean colour products only.
