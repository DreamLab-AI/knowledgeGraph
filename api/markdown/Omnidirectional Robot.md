
A wheeled mobile robot that achieves holonomic motion—the ability to translate in any direction and rotate independently—by employing mecanum wheels or omniwheels whose passive rollers allow lateral force components. This enables precise, agile manoeuvring in constrained environments such as warehouses and hospital corridors without requiring turning arcs.
