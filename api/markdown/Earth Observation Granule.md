An Earth observation granule is the smallest aggregation of data that can be independently managed, meaning described, inventoried and retrieved, within a collection of Earth observation data.[^1]

In the NASA metadata model a granule has its own metadata and carries values for additional attributes defined by the collection that owns it. The collection holds information common to all its granules, which separates collection-level description from the description of individual files or scenes.[^1][^2]

Granules sit within the processing-level scheme. A granule is a unit of management at a given level, for example raw or calibrated data, and the same scene can appear as different granules at different levels.[^3]

That definition comes from the ECHO metadata model, a system that NASA states has been retired while its data model specification remains valid. Other archives may use the word granule with different boundaries, and the sources do not fix a size, spatial extent or file count.[^1]

[^2]: Federal Geographic Data Committee, “Geospatial Metadata”. https://www.fgdc.gov/metadata
[^3]: NASA Earthdata, “Data Processing Levels”. https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/data-processing-levels
