A vertical coordinate reference system is a one-dimensional coordinate reference system based on a vertical reference frame.[^1]

A vertical reference frame, also called a vertical datum, describes the relation of gravity-related heights or depths to the Earth. In most cases it is related to mean sea level. Vertical datums include sounding datums used for hydrographic purposes, where values may be negative heights or depths.[^1]

NOAA describes a vertical datum as realised through a collection of specific points on the Earth with known heights above or below a nationally defined reference surface, for example mean sea level.[^2]

Established practice combines the horizontal coordinates of a point with a height or depth from a different vertical coordinate reference system, which the standard describes as a compound coordinate reference system.[^1] The sources describe the definition and use of the term but do not establish how any national vertical system is realised beyond these examples.[^1][^2]

[^2]: NOAA National Ocean Service, “What is a datum?” https://oceanservice.noaa.gov/facts/datum.html
