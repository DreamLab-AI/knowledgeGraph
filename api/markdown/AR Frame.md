- ### Definition
  - An AR Frame is a hardware platform combining optical see-through displays with onboard processing, sensor arrays, and wireless connectivity to deliver augmented reality experiences. Examples include the Brilliant Labs Frame, Spectacles, and Magic Leap, enabling hands-free, spatial computing applications with real-time environmental awareness and persistent [[Digital Twin]] integration.

- ### Content

  ## Overview

  AR Frames represent the next generation of spatial computing wearables, moving beyond smartphone-based AR. They feature transparent displays overlaying digital content on real-world vision, integrated processing for real-time environmental understanding, and seamless integration with digital twin systems and AI agents.

  ## Key Features
  - **Optical See-Through Display**: Transparent or semi-transparent optics preserving real-world view
  - **Onboard Processing**: Local computation for privacy and latency-critical features
  - **Sensor Suite**: Vision systems, IMU, depth sensors enabling spatial awareness
  - **Wireless Connectivity**: 5G and WiFi for cloud integration and collaboration
  - **Developer Ecosystem**: APIs and SDKs (Node Playground, frameutils) for application development

  ## Applications
  - **Productivity**: Heads-up display for navigation, communication, and task management
  - **Industrial Inspection**: Hands-free reference materials and remote expert guidance
  - **Retail**: Product information overlays and inventory management
  - **Healthcare**: Surgical guidance and patient data visualisation
