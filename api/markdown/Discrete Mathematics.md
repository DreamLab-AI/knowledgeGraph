- ### Definition
  - Discrete mathematics is the branch of mathematics concerned with structures that are fundamentally discrete rather than continuous, including sets, graphs, combinatorics, logic and number theory. It provides the formal foundations for computer science, underpinning algorithm analysis, data structures and cryptographic systems that rely on integer arithmetic and modular structures. Computer science curricula treat it as a prerequisite discipline, and fields such as number theory build directly on its results.
