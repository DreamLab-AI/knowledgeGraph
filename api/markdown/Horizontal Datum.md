A horizontal datum is the geodetic datum that fixes a reference ellipsoid against the Earth so that latitude and longitude have a defined meaning.[^1]

The OGC specification describes the choice of ellipsoid size, shape, position and orientation with respect to the Earth as captured by the concept of a geodetic datum. Traditional datums were defined so that the ellipsoid matched the geoid as closely as possible locally, for example within a country, and may be anchored at a fundamental point.[^1]

In current terminology the datum is called a reference frame, and modern frames may instead be anchored by a set of station coordinates. The retrieved text does not define the phrase horizontal datum itself, so this page uses it for the two-dimensional role of a geodetic datum; the vertical counterpart is a separate construct.[^1]

Coordinates given on different datums are not directly comparable, and the source does not give transformation methods or accuracy figures.[^1]
