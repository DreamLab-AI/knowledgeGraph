Spectral classification sorts stars into classes by the pattern of absorption lines in their spectra, and the classes measure surface temperature.[^1]

A star’s temperature determines which absorption lines are present, so the line pattern identifies a spectral class. There are seven standard classes, which from hottest to coldest are O, B, A, F, G, K and M, and astronomers have added the classes L, T and Y for still cooler objects.[^1] The textbook adds that the Y class is still being defined.[^1]

Each class is divided into ten subclasses numbered from 0 to 9, with 0 the hotter end. The Harvard-Smithsonian atlas describes the types and subclasses together as a temperature sequence from hotter to cooler.[^2] The textbook credits Annie Jump Cannon with rearranging the earlier lettered classes into this order of decreasing temperature.[^1]

A spectral class is a statement about surface temperature and line pattern, not about mass, age or size. The atlas also assigns a separate luminosity class to standard stars, but the passage used here does not define it.[^2] The two sources list somewhat different temperature boundaries for some classes, so any boundary should be read as approximate.[^1][^2]
