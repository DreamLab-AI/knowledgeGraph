Earth observation Level 4 is the stage at which lower-level data have been combined with a model or analysis to give derived results such as complete fields.[^1][^2]

SWEET's state data processing module defines Level4 as a processing level whose data have had an assimilation process, and it declares L4 as an equivalent class of Level4.[^1] Unlike Level2 and Level3, the Level4 definition carries no data model restriction, so it does not fix a swath or a grid.[^1]

This page names a state of data, while the Level 4 data product page names the packaged dataset that is in that state. CEOS describes Level 4 as model output or analyses of lower-level data, and the Metrologia review adds that Level 4 analyses may ingest in situ values as well as satellite data.[^3][^4]

Retained sources do not establish that every NASA or CEOS Level 4 product is built by assimilation, since NASA also counts results of analyses, so the SWEET state is narrower than the product class.[^1][^2]
