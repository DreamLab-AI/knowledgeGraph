- ### Definition
  - [[Taproot]] is the most significant upgrade to the Bitcoin protocol since SegWit, activated at block 709,632 in November 2021 through a soft fork comprising BIPs 340, 341, and 342. BIP 340 introduces Schnorr signatures, which are linearly aggregatable and shorter than ECDSA signatures. BIP 341 introduces Pay-to-Taproot (P2TR), using a Merkelised Abstract Syntax Tree (MAST) structure to commit to all possible spending conditions while revealing only the executed branch. BIP 342 introduces Tapscript, an updated [[Bitcoin Script]] variant enabling richer spending condition expressions within the MAST framework.

- ### Relationships
  - Taproot is a direct upgrade to the [[Bitcoin Network]] and builds on [[Bitcoin Improvement Proposals]] as its standardisation vehicle. It employs [[Cryptographic Signature]] innovation (Schnorr) and [[Cryptographic Primitive]] composition (MAST, key aggregation) to achieve its goals. Taproot is a prerequisite for and enabler of [[Taproot Assets]] (formerly Taro), the protocol for issuing assets on Bitcoin. Its scripting layer is rooted in the [[Bitcoin Script]] heritage and is described technically in [[Bitcoin Technical Overview]] contexts.

- ### Content
  - Taproot's development was initiated by Gregory Maxwell's 2018 proposal, synthesising earlier ideas around Schnorr signatures (long discussed for Bitcoin) and MAST (introduced by Johnson Lau in 2016). A developer community process through 2019–2020 refined the three BIPs, and the Speedy Trial activation mechanism achieved miner lock-in in June 2021, with activation following in November. The upgrade was notable for avoiding the contentious forks that had characterised earlier Bitcoin governance disputes.

  - The core technical innovation is the key-path/script-path spending duality. A P2TR output commits to a key Q = P + H(P, m)G, where P is an internal key and m is the MAST root. If all parties cooperate, spending via the key path produces a single Schnorr signature indistinguishable from a simple single-key spend. Only if cooperation fails is the MAST revealed and a script-path spend executed, preserving privacy for the cooperative case. Schnorr's linearity also enables MuSig2 key aggregation for multi-party signing, compressing n-of-n multisignature schemes into a single key-sized output.

  - The Taproot ecosystem has grown to encompass wallet support (hardware and software wallets have progressively added P2TR support), Lightning Network enhancements (taproot channels reduce on-chain footprint), and the Taproot Assets protocol developed by Lightning Labs, which leverages MAST commitments to issue fungible and non-fungible assets on Bitcoin with Lightning-routable transfers.

  - In 2024–2025, Taproot adoption has steadily increased, with a growing percentage of Bitcoin transactions using P2TR outputs. The protocol has become the foundation for second-layer innovations including [[Taproot Assets]] stablecoins and the BitVM computation paradigm, which uses Tapscript's expressiveness to implement optimistic verification of arbitrary computations on Bitcoin without a hard fork, marking a significant expansion of programmability on the base layer.
