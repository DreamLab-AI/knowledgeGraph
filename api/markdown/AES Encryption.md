AES encryption is the Advanced Encryption Standard, a symmetric block cipher adopted as a US federal standard that operates on fixed-size blocks using a shared secret key for both encryption and decryption. It is the most widely deployed symmetric cipher, used by hardware security features such as Intel SGX for memory encryption and by low-power wireless protocols such as Zigbee for link-layer security. It supports 128, 192 and 256-bit key lengths, with 128-bit remaining secure against all known practical attacks.
