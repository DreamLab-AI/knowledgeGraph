Raspberry Pi is a family of low-cost, credit-card-sized single-board computers built around ARM systems-on-chip, designed originally for education and now ubiquitous in hobbyist, prototyping, and edge-computing deployments. It exposes GPIO pins for hardware interfacing and runs full Linux distributions, making it a versatile platform for home automation, robotics controllers, and small servers. Its affordability and large community make it a default choice for edge experimentation.

### Content

- With models spanning microcontroller-class (Pico) to multi-core 64-bit boards, the Pi suits edge inference, sensor gateways, and robot controllers. GPIO, I2C, SPI, and camera interfaces enable direct hardware control, while the broad OS and software ecosystem lowers the barrier for self-hosted services and prototyping.
