
A data contract is a formal, versioned agreement between data producers and consumers that specifies the schema, semantics, quality guarantees and service-level expectations of a dataset or stream. It makes data interfaces explicit and enforceable, enabling automated validation and breaking-change detection in data pipelines. Data contracts are a metadata-management practice that improves reliability and trust across decentralised data ownership.

- ### Content
  - By codifying expectations between producers and consumers, contracts allow pipelines to validate incoming data and detect breaking schema changes before they propagate. They are central to data-as-a-product and data-mesh approaches where ownership is distributed across teams.
