Semantic reasoning is the process of deriving new facts or checking consistency by applying logical inference rules to formally represented knowledge, such as an ontology or knowledge graph, rather than to raw text or numeric data. It exploits explicit semantics, including class hierarchies and property definitions, to infer relationships not directly asserted, for example that an individual belongs to a class through transitive subsumption. Semantic reasoning underlies description-logic reasoners and is affected by whether a knowledge base assumes an open- or closed-world semantics.
