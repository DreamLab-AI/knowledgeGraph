A variable stiffness actuator (VSA) is a compliant robotic actuator whose mechanical stiffness can be adjusted independently of its position, typically using antagonistic springs or adjustable elastic elements. This adjustable compliance lets robots store and release energy, absorb impacts and interact safely with humans and uncertain environments. VSAs are central to safe, energy-efficient force control in physical human-robot interaction.

### Content

- VSAs use antagonistic spring arrangements or mechanically tunable elastic transmissions to set stiffness on demand. Lowering stiffness improves safety and impact absorption, while raising it enables precise positioning, making VSAs valuable for collaborative robots, prosthetics and dynamic locomotion.
