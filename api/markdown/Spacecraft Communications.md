
Spacecraft communications is the exchange of information between a spacecraft and other endpoints through space and ground communication systems.

A mission communication system can connect a spacecraft to one or more Earth stations, another spacecraft, or a relay that provides a route to Earth. The end-to-end system includes the spacecraft communication equipment, intervening links, ground stations and the interfaces that deliver data to mission systems. A route through a relay consists of separate links; it should not be described as a single direct spacecraft-to-ground link.[^1][^3][^10]

Radio-frequency (RF) links are widely used, while free-space optical links are also implemented. NASA’s ILLUMA-T and Laser Communications Relay Demonstration completed a two-way end-to-end optical relay demonstration with an International Space Station user in December 2023. This records a demonstrated configuration and does not establish universal adoption or a guaranteed operational service.[^1][^10]

Communication carries more than telemetry, tracking and command (TT&C). Missions may exchange commands, spacecraft health and status, science observations, Earth-observation products, video, software, files or user traffic. In mission operations, TT&C commonly names the narrower health, status, tracking and command functions; some CCSDS material also uses “telecommand” and “telemetry” broadly for data in each transmission direction, so the intended meaning should be stated.[^2][^4]

Performance belongs to the complete link and route. Transmitter power, antenna gain and pointing, propagation loss, receiver noise, modulation, coding, data rate, ground-station choice and required margin all affect whether a link closes. Ground access, geometry and weather can constrain service; a spacecraft has no fixed link margin independent of its station and operating conditions.[^1][^2][^4]

CCSDS recommendations define interoperable protocols and physical-layer options at specified layers. They do not by themselves provide spectrum rights, authorise a station, select a ground network or create an end-to-end cross-support arrangement. CCSDS describes its Blue Books as recommended standards, and the telecommand protocol specifies that endorsement is voluntary and service arrangements require agreement. Link-layer security is likewise a selected mechanism: the CCSDS Space Data Link Security Protocol supports authentication and/or confidentiality for specified data-link protocols, but does not secure every ground or mission system automatically.[^5][^6][^7][^8][^9]
