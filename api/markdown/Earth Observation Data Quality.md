Earth observation data quality is the degree to which an Earth observation data product meets stated requirements for calibration, uncertainty, consistency and documentation.[^1][^2]

Observing-system principles from GCOS call for the quality and homogeneity of data to be assessed as part of routine operations, and for calibration to be traceable to reference standards. These are principles for climate observing, so they set expectations rather than a single quality score.[^1]

Processing level matters to what quality can mean. Level 0 products are raw instrument data, and later levels add calibration and georeferencing information, so a quality statement is tied to the level at which it was made.[^3] The CEOS Analysis Ready Data framework approaches the same problem by assessing products against specified metadata, radiometric, atmospheric and geometric correction criteria, while describing its definition as neither exclusive nor prescriptive.[^2]

A quality statement is therefore specific to a product, version and assessment method. The sources here do not give one universal metric, and geolocation, radiometric and metadata quality are assessed separately.[^2][^3]

[^2]: CEOS, “CEOS Analysis Ready Data”. https://ceos.org/ard/
