Plot is the visualisation of data values as a graphic such as a map, line plot or contour plot.[^1][^2]

NASA describes Giovanni as a web application that displays and analyses geophysical parameters in remote sensing data, with services that include time-averaged maps, comparison plots, vertical plots and animations.[^1] The NASA GISS Panoply viewer creates colour contour plots of geo-referenced arrays and line plots of data from one-dimensional or larger multidimensional variables.[^2]

Both tools plot data that already exist at a processed level, and NASA places gridded and analysed variables at its higher levels.[^3] Plotting presents values and does not itself change the processing level of the underlying product.

Retained sources describe two tools and not a general definition, so the boundary with wider data visualisation, and any standard for plot content, is not established here.[^1][^2][^3]

[^3]: NASA Earthdata, “Data Processing Levels”. https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/data-processing-levels
