Subsetted data state is the state of a dataset after a subset process has been applied to it, and SWEET defines it as a data state that had a subset process [^1].

A subset is a set that is part of a larger set, and NASA's subsetters let users narrow data by parameter, time range and geographic area [^2]. For some products the service allows users to request spatial, temporal and variable subsets, which can significantly reduce the size of the files made available for download [^3].

Selection by time or area returns any available data that intersects the chosen range or region, so a subsetted granule can include material beyond the request [^2]. The retained sources do not establish how a subset changes processing level, nor whether subsetting preserves quality flags or metadata.
