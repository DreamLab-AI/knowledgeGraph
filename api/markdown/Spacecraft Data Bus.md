A spacecraft data bus is an onboard communication link or network over which spacecraft units exchange commands and data under a defined interface protocol.[^1][^2]

ECSS defines interface services and bus protocol elements for MIL-STD-1553B devices connected to a single, redundant data bus.[^1] SpaceWire grew out of onboard data handling needs, and ESA describes its nodes as joined by full-duplex point-to-point serial links and switches, making it a switched network rather than a shared bus, although it is often discussed alongside buses.[^3][^2]

Avionics in NASA's small-spacecraft survey may be centralised or distributed. A central onboard computer might handle power and housekeeping on an internal backplane, with payload processors and interface modules connecting via SpaceWire or Ethernet cables, allowing one spacecraft to support multiple data links.[^4]

In NASA's overview of onboard systems the word bus names the structural body of a spacecraft, which carries attachment points for booms, antennas and scan platforms. That sense is separate from the data path discussed here. The sources do not establish a single definition of a data bus, nor performance figures for any bus type.[^5]
