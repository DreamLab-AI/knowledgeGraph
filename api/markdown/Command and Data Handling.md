Command and data handling is the spacecraft function, usually provided by an onboard computer and its associated units, that receives and stores commands, processes and packages data, and prepares telemetry for transmission to the ground.[^1][^2]

NASA's deep-space description calls the computer the command and data subsystem (CDS) on some spacecraft and notes that names vary. In that description the CDS holds uplinked command sequences, maintains the spacecraft clock and assembles telemetry from instruments and engineering subsystems into frames or packets, with the option of compression and encoding.[^1]

Fault protection and safing routines are placed in CDS memory by NASA's description, where they can be updated during a mission.[^1] ESA describes onboard data systems as a set of functional blocks including telecommand and telemetry modules, onboard computers, mass memories, remote terminal units, protocols and buses, and calls the onboard computer the central core of the spacecraft avionics.[^2]

ESA's terms (spacecraft management unit, command and data handling management unit) and NASA's CDS describe the same kind of role, but the sources do not establish that the functional split is identical across missions. They also do not specify processor types, data rates or software architecture for any particular spacecraft.[^1][^2]
