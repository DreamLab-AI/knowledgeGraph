An Earth observation data processing level is a label that states how far a data product has been taken from the raw instrument data towards derived, gridded or modelled results.[^1]

In the NASA Earth Observing System Data and Information System scheme the levels run from Level 0 to Level 4. Level 0 is raw data at full instrument resolution, and at higher levels the data are converted into more useful parameters and formats. The same page says every NASA Earth Observing System instrument must have Level 1 standard data products, while most have Level 2 and Level 3 products and many have Level 4 products.[^1]

Other missions apply the vocabulary to their own processing chains. Sentinel-2 documentation describes a Level-0 product of raw image data followed by Level-1A and Level-1B stages, and Sentinel-1 documentation treats Level-0 as raw SAR data and Level-1 as focused products.[^2][^3] The SAR Handbook likewise treats raw SAR data as Level 0 and single look complex data as Level 1, and notes an exception in how one sensor names its raw data.[^4]

A level number is therefore best read as a position within a named scheme, not as a fixed technical specification. The sources opened here do not show that the NASA, ESA and SAR community usages are interchangeable, and a user needs the issuing agency's product description to know what corrections a given product has received.[^1][^2][^3][^4]
