
Cinematic Rendering is a rendering approach that prioritises photorealistic, film-quality visual output over real-time frame rates, applying techniques such as ray tracing, physically based materials, depth of field, and colour grading. It is used for pre-rendered animation, marketing visualisation, and offline previsualisation rather than interactive applications. It builds on general rendering techniques but trades real-time performance for image fidelity.
