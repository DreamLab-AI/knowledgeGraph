A spectral band is a defined interval of wavelengths over which an instrument records radiation, so that an image is built from several such intervals.[^1][^2]

The Royal Meteorological Society describes every satellite image as consisting of several bands or channels, each representing a different wavelength interval. The ESA page lists the 13 bands of the Sentinel-2 imager, which are sampled at three different spatial resolutions.[^1][^2]

Bands are chosen for applications and revised between missions. NASA states that new or refined bands have been added to Landsat missions since 1972, and that the Landsat 8 Operational Land Imager added a coastal blue band for coastal ocean-colour work and a shortwave-infrared band that senses strong water-vapour absorption, which allows detection of cirrus clouds.[^3]

Band sets are specific to an instrument, so a band number or width quoted for one mission does not carry over to another. The width of a band is a separate property from the number of bands, and is the subject of spectral resolution.[^2][^3][^4]
