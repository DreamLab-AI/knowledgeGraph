A spacecraft thermal model is a numerical representation of a spacecraft and its surroundings as thermal capacitance nodes coupled by conductors, used to predict temperatures.[^1][^2]

ECSS standards define a thermal mathematical model with radiative, conductive and convective conductors between nodes, noting that it can be built by lumped parameter, finite difference or finite element methods.[^1] A lecture offers an electrical analogy in which heat flow maps to current and temperature to voltage, which permits temperatures to be predicted as a function of time.[^2]

In practice the lumped parameter method is widely used for spacecraft thermal analysis, and models are correlated with thermal test or flight data to improve the accuracy of temperature predictions.[^3] Inputs such as coating properties change over a mission, and NASA advises that thermal analysis bias the optical property values in the models to account for degradation.[^4]

Term and structure definitions appear in the standard, but not accuracy metrics for any model; the lecture is a teaching text from 2003. The standard edition consulted dates from 2008, and a later revision was not checked.
