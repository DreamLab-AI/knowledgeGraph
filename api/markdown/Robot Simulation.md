Robot simulation is the use of physics-based virtual environments to model a robot's kinematics, dynamics, sensors, and interactions before or instead of deploying on hardware. It enables developers to test control software, validate motion plans, and generate training data safely and cheaply. Tight integration with robot middleware lets the same code run in simulation and on the physical robot.

### Content

- Simulators compute rigid-body dynamics, contacts, and synthetic sensor data so control stacks can be exercised without hardware risk. Running identical middleware in simulation and reality supports rapid iteration, regression testing, and large-scale reinforcement learning.
