
A Configuration Setting is a named parameter or preference value that governs the runtime behaviour of a spatial computing application, platform, or XR experience. Configuration settings control rendering quality, user accessibility options, privacy preferences, and network parameters, and are typically persisted across sessions to maintain consistent user experiences within metaverse and immersive environments.
