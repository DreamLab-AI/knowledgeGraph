An onboard computer is the processor-based unit on a spacecraft that runs flight software and manages spacecraft operations as part of command and data handling.[^1]

NASA small-spacecraft guidance says its capability is set by the hardware, including board design, processor choice, memory architecture, power conditioning and radiation tolerance. NASA Basics describes a central spacecraft computer that maintains timing, interprets commands from Earth, formats telemetry and runs high-level fault protection, and notes that instruments and other subsystems may carry substantial computing of their own.[^2][^1]

Fault protection is one use of this computing. NASA Basics describes a command-loss timer that, when it runs out, triggers actions such as swapping to redundant hardware to try to restore command reception. The NASA avionics chapter treats radiation as a major design factor and discusses mitigation schemes.[^2][^1]

Architectures vary between a single central computer and distributed processors, and the sources use several names for overlapping functions. They do not identify a best processor type for all missions or set performance figures.[^2][^1]
