Mapped data state is the processing state of data that has undergone a mapping process [^1].

In the SWEET ontology the class is a subclass of the data state class, restricted to data that had a mapping process [^1]. The file does not define mapping itself, so the scope comes from elsewhere. NASA describes Level 3 data as variables mapped on uniform space-time grid scales, while Level 2 variables stay at the resolution and location of the source data [^2].

Whether every mapped state is a gridded one is not established by the retained sources, and neither source gives a quality measure for the state.

[^1]: ESIP SWEET ontology (GitHub), “SWEET State Data Processing (Turtle)”. https://raw.githubusercontent.com/ESIPFed/sweet/master/src/stateDataProcessing.ttl
[^2]: NASA Earthdata, “Data Processing Levels”. https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/data-processing-levels
