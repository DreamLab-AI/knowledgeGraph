Spacecraft housekeeping data is the engineering and health telemetry that describes the state of the spacecraft itself, such as switch positions, subsystem states, voltages, temperatures and pressures.[^1]

NASA describes this engineering or health data as being collected by the command and data subsystem and inserted into the telemetry stream. In an anomaly it may be necessary to stop collecting science data and return only an enriched or specialised stream of engineering and housekeeping data.[^1]

ECSS packet utilisation standard defines telecommand and telemetry packets used for remote monitoring and control of spacecraft subsystems and payloads, though it is not meant to be applied in its entirety to a given mission, and the summary read here does not say which housekeeping parameters a mission should carry.[^2]

Housekeeping also names a function, with NASA's avionics survey giving the example of a central onboard computer using a backplane for power and housekeeping functions. The sources do not give one agreed boundary between housekeeping data and other engineering data.[^3]
