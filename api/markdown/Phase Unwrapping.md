Phase unwrapping is the stage of interferometric processing that resolves the ambiguity of a wrapped phase measurement so that phase differences between pixels relate to actual height or displacement.[^1]

The Alaska Satellite Facility states that the interferometric phase is ambiguous and only known within 2π, and that unwrapping solves this by integrating phase difference between neighbouring pixels.[^1] Once an interferogram is unwrapped, its guide says height values can be derived for further products such as deformation maps or digital elevation models.[^1]

That guide calls unwrapping the most complicated stage of interferometric data processing and ties its reliability to coherence: reliable results can only be expected in areas with high coherence.[^1] It names SNAPHU as the two-dimensional algorithm it uses and does not compare other algorithms.

The NASA processing levels page lists levels from raw data to analysis results but does not name phase unwrapping or assign it to a level.[^2] The retained sources therefore do not establish at which level unwrapped phase is delivered, nor any numerical coherence threshold.[^1][^2]

[^1]: Alaska Satellite Facility, “Sentinel-1 InSAR Phase Unwrapping using S1TBX and SNAPHU”. https://asf.alaska.edu/wp-content/uploads/2019/02/insar_phase_unwrapping_v8.1.pdf
[^2]: NASA Earthdata, “Data Processing Levels”. https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/data-processing-levels
