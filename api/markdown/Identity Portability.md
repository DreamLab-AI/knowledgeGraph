
Identity portability is the capacity for a user to move their digital identity, credentials, and associated reputation across platforms, services, or virtual worlds without re-establishing them from scratch. It relies on interoperable identity standards and user-controlled wallets so that authentication and verified attributes remain valid across boundaries. Portability is a cornerstone of self-sovereign identity and an open metaverse.

- ### Content
  - Portability depends on decentralised identifiers, verifiable credentials, and wallets that the user rather than a platform controls. By decoupling identity from any single provider it reduces lock-in and lets verified attributes such as age, membership, or ownership travel with the user across the open web and immersive environments.
