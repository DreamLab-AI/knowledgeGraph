Earth observation Level 3 is the stage at which Level 2 data have been gridded onto a uniform space-time grid.[^1][^2]

SWEET's state data processing module defines Level3 as a processing level whose data have had a gridding process and whose data model is a grid, and it declares L3 as an equivalent class of Level3.[^1] NASA places the same stage in its scheme as variables mapped on uniform space-time grid scales.[^3]

This page names a state of data, while the Level 3 data product page names the packaged dataset that is in that state. The Metrologia review describes the transformation as aggregation of Level 2 values within each grid cell, usually by averaging.[^4]

SWEET gives no definition text for Level3 beyond its restrictions, and the retained sources do not establish whether a gridded but gap-filled dataset is still Level 3 in SWEET terms.[^1][^4]
