A horizontal coordinate system is a two-dimensional coordinate reference system, such as geodetic latitude and longitude or projected northing and easting, that is paired with a vertical system when a height is needed.[^1]

A coordinate reference system consists of a coordinate system and a datum, and modern geodetic terminology calls the datum a reference frame. A horizontal and a vertical system can be combined in sequence, and a temporal system may be added to give a compound system.[^1]

A different usage defines a frame at an observing site. Navipedia describes local East, North and Up axes related to Earth-fixed coordinates through the site's latitude and longitude, with elevation and azimuth computed in that frame. The NAIF documentation defines a topocentric frame at a surface point whose x-axis points north along the local meridian.[^2][^3]

Axis order and handedness differ between the two documents and matter when exchanging such frames. The sources do not establish whether the seeded ontology term is meant in the geodetic sense or the observer-centred sense.[^2][^3]
