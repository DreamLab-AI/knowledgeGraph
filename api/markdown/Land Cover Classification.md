Land cover classification is the assignment of each pixel or area of an image to a class describing the observed physical cover of the earth's surface, which yields a thematic map [^1][^2].

Digital classification uses the spectral information in one or more bands to classify each pixel, and the analyst must match spectral classes to the information classes of interest, a match that is rarely simple or one to one [^1]. FAO defines land cover as the observed (bio)physical cover on the earth's surface, and USGS gives water and pavement as examples of physical features [^2][^3].

Land cover classification is narrower than land use classification, because FAO warns that many existing legends confuse cover with use [^2]. NASA treats results of analyses of lower-level data as Level 4 output, although its page does not name land cover classification [^4]. ESA notes that AI applications in Earth observation have mainly used computer vision techniques for interpreting satellite imagery [^5].

Across the retained sources, there are no accuracy figures, no standard legend and no ranking of classification algorithms.
