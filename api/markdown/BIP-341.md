- ### Definition
  - [[BIP-341]] defines the Taproot upgrade to [[Bitcoin Network]], combining [[Schnorr Signature]] aggregation via [[BIP-340]] with [[Merkle Tree]]-based script commitments (MAST) to enable private, flexible spending conditions within the [[UTXO Model]].
- ### Relationships
  - BIP-341 builds directly on [[BIP-340]] for its Schnorr signature foundation and uses [[Merkle Tree]] structures to commit multiple [[Script]] spending paths in a single output. It underpins the [[Taproot Assets]] protocol and interacts with [[Cryptographic Commitment]] schemes to ensure on-chain privacy. The [[Bitcoin Network]] consensus rules enforce the Pay-to-Taproot output type, and [[Bitcoin Improvement Proposals]] governance coordinated the soft fork activation.
- ### Content
  - BIP-341 introduces Pay-to-Taproot (P2TR) as a SegWit v1 output type. A P2TR output commits to a single internal public key and an optional [[Merkle Tree]] of alternative script spending paths. When spending via key path, only a single [[Schnorr Signature]] is broadcast, indistinguishable from a simple single-sig spend regardless of the underlying script complexity. This dramatically improves privacy for multisig wallets, lightning channels, and other contract constructs.

  - The Merklised Alternative Script Tree (MAST) component allows wallets to commit to an arbitrary number of spending conditions in logarithmic space on-chain. Only the satisfied script leaf and its Merkle proof are revealed at spend time, keeping unexecuted branches private. This substantially reduces on-chain footprint for complex contracts and closes longstanding script size bottlenecks that had constrained advanced Bitcoin use cases.

  - Activation was achieved via the Speedy Trial mechanism, reaching the required 90% miner signalling threshold in June 2021 and locking in at block 687,285 before activating at 709,632 in November 2021. The upgrade is a soft fork, meaning all pre-Taproot nodes continue to validate the chain but cannot enforce the new rules. The [[Bitcoin Core]] implementation (v22.0) shipped full Taproot support alongside BIP-341.

  - [[Taproot Assets]] (formerly Taro) is a higher-level protocol that leverages BIP-341's script tree mechanism to embed asset metadata in Taproot outputs, enabling token issuance on Bitcoin without altering the base layer consensus. The privacy properties of BIP-341 also benefit the Lightning Network, as cooperative channel closures and complex payment paths can now use key-path spending, reducing the traceability of channel activity.
