- ### Definition
  - Enterprise search is the organisational capability to retrieve relevant information from heterogeneous internal data sources—documents, databases, emails, intranets, and code repositories—within a single unified query interface. Modern enterprise search systems increasingly combine full-text indexing with semantic retrieval, vector embeddings, and retrieval-augmented generation (RAG) to surface contextually relevant results rather than mere keyword matches. The discipline sits at the intersection of information retrieval, knowledge management, and applied AI, requiring connectors, access-control enforcement, and relevance tuning at scale.

- ### Content
  Enterprise search differs from public web search in several critical respects: it must respect fine-grained access controls (ensuring employees only retrieve documents they are authorised to view), handle a wide variety of proprietary formats (PDFs, SharePoint pages, Confluence wikis, SQL tables), and integrate tightly with organisational identity providers via standards such as SAML or OAuth.

  Traditional implementations relied on inverted-index engines such as Apache Solr and Elasticsearch, augmented by BM25 ranking. Contemporary systems layer semantic search capabilities on top, using dense vector embeddings generated by models such as BERT or domain-adapted sentence transformers. These embeddings are stored and queried in vector databases, enabling retrieval of semantically relevant results even when exact keyword overlap is absent.

  Retrieval-Augmented Generation (RAG) architectures have become a dominant paradigm: a search layer retrieves relevant document chunks, which are passed as context to a large language model to synthesise a grounded answer. Knowledge graphs can further enrich results by surfacing entity relationships across the corpus. Natural Language Processing techniques—named-entity recognition, query rewriting, and question decomposition—improve query understanding. Enterprise search deployments must also address latency, freshness (near-real-time indexing), and explainability so users trust and act on results.
