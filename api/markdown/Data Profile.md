A data profile is a representation of values arranged along a path or axis, which SWEET models as a kind of representation related to its profile class in the mathematical-function module.[^1]

In Earth observation the common case is a vertical profile. NASA describes the Microwave Limb Sounder as an instrument that measures microwave thermal emission from the limb of the atmosphere to sense vertical profiles of atmospheric gases, temperature, pressure and cloud ice.[^2]

The SWEET source gives the class relations and a label without prose, so it does not establish what quantities or dimensions a profile must have.[^1] The NASA page shows a vertical use and does not show that every data profile is vertical, or that every profile is measured by limb sounding.[^2]

A profile should not be confused with a metadata profile, which is a different use of the word, nor with a gridded field that covers a horizontal area. Documentation for a dataset is needed to know the coordinate along which its values are arranged.

[^2]: NASA Earthdata, “Microwave Limb Sounder (MLS)”. https://www.earthdata.nasa.gov/data/instruments/mls
