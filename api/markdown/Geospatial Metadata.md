Geospatial metadata is information describing maps, Geographic Information Systems files, imagery and other location-based data resources.[^1]

The Federal Geographic Data Committee compares a metadata record to a library catalogue record, documenting the who, what, when, where, how and why of a data resource. Records formatted to a common standard are easier for people and machines to locate and read.[^1]

In NASA's Earth observation metadata model, description exists at two levels. Collection metadata describes information common to a set of products, while each granule has its own metadata.[^2]

GCOS principles state that instruments, operating procedures, processing algorithms, data errors and biases should be documented and treated with the same care as the data themselves. CEOS Analysis Ready Data specifications likewise list general and per-pixel metadata among their requirements.[^3][^4] The sources opened here do not cover the content of international standards for geographic metadata.[^3]
