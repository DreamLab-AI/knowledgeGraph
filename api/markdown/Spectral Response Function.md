A spectral response function is the sensitivity of an instrument band to radiation as a function of wavelength, used to define what a band measures.[^1]

In the Sentinel-2 documentation the equivalent wavelength of a band is described as the barycentre of the band's spectral response function, without weighting by solar irradiance. The sources do not give a general formula for every sensor, so that convention should be read as one mission's choice.[^1]

Natural Resources Canada uses the related term spectral response for a target: the pattern of reflected or emitted energy built up by measuring over several wavelengths. Comparing those patterns can separate features that look alike at a single wavelength, and the response of a target can vary with time and location.[^2]

Spectral resolution is a different quantity. It describes the ability of a sensor to define fine wavelength intervals, with finer resolution meaning narrower bands. The retained sources do not show how a response function is measured or calibrated, and the target sense and the instrument sense of spectral response should not be conflated.[^3]
