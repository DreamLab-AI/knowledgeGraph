An Earth observation data archive is an organisation-operated system of hardware, software, information and policy-based processes that preserves Earth observation data and makes it available to users.[^1]

The Open Archival Information System reference model, published by CCSDS, sets out a common framework of terms and concepts for such archives. It is a generic model for space data and is not specific to Earth observation, so it describes functions and responsibilities rather than any particular centre's holdings.[^1] The model allows an archive to be a single organisation performing all functions with its own equipment, and it also shows distributed arrangements as examples.[^1]

SWEET treats an archive as a kind of collection and as equivalent to archiving, and it also has a data state called archived.[^2][^3] The ontology provides these relations without prose definitions, so it should be read as vocabulary alignment and not as a description of how any archive works.[^2]

An archive is not the same as a catalogue or a processing system. The sources reviewed do not describe any specific Earth observation centre, so retention periods, access policies and formats are matters for the operator's own documentation.
