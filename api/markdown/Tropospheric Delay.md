
Tropospheric delay is the extra GNSS signal-path delay conventionally attributed to the electrically neutral lower atmosphere.

In GNSS and geodesy, the term often describes neutral-atmosphere propagation along the full satellite-to-receiver path. At GNSS microwave frequencies this delay is treated as non-dispersive: it lengthens both code and carrier path observations, unlike the frequency-dependent ionospheric effect.[^1]

Models commonly separate the zenith hydrostatic (often called dry) delay from the zenith wet delay, then map each component to the satellite’s slant elevation path. Surface pressure provides a useful estimate of the more predictable hydrostatic contribution; water vapour makes the wet component more variable. The mapping function, meteorological data, local gradients and elevation all affect the correction and its residual.[^1][^2]

A low-elevation line of sight has a longer path through the neutral atmosphere and is more sensitive to mapping and local model errors than a near-zenith path. A correction is therefore an estimate, not proof that the remaining coordinate error is negligible.[^1][^2]

Galileo’s published tropospheric-model description documents an older model with ERA-15-derived coefficients. It helps explain the hydrostatic/wet and mapping structure, but the source does not establish that model as the current operational receiver algorithm.[^1]
