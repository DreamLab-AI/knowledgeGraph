Orthometric height is a gravity-related height that approximates the distance of a point above mean sea level.[^1]

According to the reference standard, orthometric height is grouped with Normal height and similar quantities as heights that depend on the Earth’s gravity field, and orthometric and Normal heights are approximations of the distance above mean sea level.[^1] It does not set out how orthometric height is computed, so this page does not either.

Mean sea level is represented by the geoid, which NOAA describes as a model of global mean sea level used to measure precise surface elevations.[^2] Ordnance Survey adds that the geoid is never more than a couple of metres from local mean sea level, and that heights in mainland Britain are referred to a tide gauge at Newlyn, which gives a surface somewhat below the geoid.[^3]

Orthometric height is distinct from ellipsoidal height, which is measured along the perpendicular to a reference ellipsoid and is used only as part of a three-dimensional coordinate system.[^1] Ordnance Survey notes that a point can have a greater ellipsoid height than another point while lying downhill of it.[^3]

Terminology differs between sources. Ordnance Survey equates geoid height with orthometric height, whereas the OGC standard uses geoid height for the separation between the geoid and the reference ellipsoid.[^3][^1] Readers should check which sense a dataset uses.
