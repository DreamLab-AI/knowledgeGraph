A validation dataset is a set of reference data against which satellite-derived product values are compared to assess their accuracy.[^1]

The CEOS Land Product Validation subgroup coordinates quantitative validation of satellite-derived products. Its higher validation stages quantify uncertainties by comparison with reference in situ or other suitable reference data, and its framework rests on a citable protocol, fiducial reference data and automated subsetting.[^1]

QA4EO links quality indicators to traceability to reference standards, which bears on how far a reference dataset can be trusted as a comparison.[^2] AERONET offers a ground-based example: sun photometer measurements of direct solar radiation yield columnar aerosol optical depth, with processing levels that depend on post-field calibration.[^3]

None of the cited pages defines validation dataset as a term, and AERONET is not described there as one. A reference dataset still has its own uncertainty and sampling limits, which the sources do not quantify.[^1][^2][^3]

[^2]: CEOS and ESA, “Quality Assurance Framework for Earth Observation (QA4EO)”. https://qa4eo.org/
[^3]: NASA AERONET, “Aerosol Optical Depth (V3) - Solar”. https://aeronet.gsfc.nasa.gov/new_web/aerosols.html
