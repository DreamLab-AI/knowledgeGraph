Absolute magnitude is the magnitude a star or galaxy would have if it were placed at a standard distance of 10 parsecs from the observer.[^1][^2]

Fixing the distance removes the effect of how far away an object actually is, so the value measures intrinsic brightness. Apparent magnitude depends partly on distance, which is why two objects with the same apparent magnitude can differ greatly in intrinsic brightness.[^2][^3]

Absolute magnitude uses the same scale as apparent magnitude, and it runs backwards: a lower value means greater intrinsic brightness.[^1][^2]

Sources used here define the quantity for stars and galaxies in general terms. They do not fix a photometric band or an extinction correction, so a stated value needs its band and any correction identified before it is compared with another. It is also a brightness measure rather than a complete account of total energy output.
