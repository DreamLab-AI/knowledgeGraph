A space life sciences dataset is a data set of space life sciences observations, meaning an aggregate of data items of the same type that have something in common.[^1][^2]

NASA's Open Science Data Repository and Physical Sciences Informatics provide open access to biological and physical science datasets from spaceflight and ground studies, with the stated aim of enabling reuse for discovery and innovation.[^2] Reuse is a stated purpose and not a measured outcome.

NASA names the Open Science Data Repository, which combines GeneLab and the Ames Life Sciences Data Archive, and the Physical Sciences Informatics database as its principal repositories.[^3] Repository structure can change, so this reflects the pages as retrieved.

Ontology wording for datasets is generic, and the retained sources do not set a minimum size, format or licence for such a dataset.[^1][^2]
