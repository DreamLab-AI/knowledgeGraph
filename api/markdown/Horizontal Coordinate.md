A horizontal coordinate is a position value on the two-dimensional, surface-following part of a reference system, such as geodetic latitude and longitude on a reference ellipsoid.[^1]

In geodetic practice the horizontal coordinates of a point are combined with a height or depth taken from a separate vertical reference system. When a map projection is applied, the horizontal coordinates become northing and easting, while any ellipsoidal height is left unchanged.[^1]

Observer-centred frames also use this term, in which a line of sight is described by elevation and azimuth in local East, North and Up axes. The sources retrieved define those local frames but do not apply the term horizontal coordinate to them, so the link between the two senses is an editorial reading rather than a stated equivalence.[^2][^3]

A horizontal coordinate has no stated meaning without its reference system and datum. The same latitude and longitude pair refers to different places under different datums, and a horizontal pair alone does not fix a height.[^1]
