- ### Definition
  - BIP-330 specifies transaction reconciliation (Erlay) to cut bandwidth used in mempool gossip, strengthening the network layer that carries [[Taproot Assets]] activity.
- ### Content
  - Using minisketch-based set reconciliation, peers exchange compact sketches to discover differing transactions rather than flooding announcements. This lowers per-node relay bandwidth roughly linearly with connectivity and reduces the network footprint that adversaries can observe.
