
Real-time animation is the generation or playback of character and object motion at interactive frame rates, computed live rather than pre-rendered, so that the animation can respond immediately to input or simulation state. It relies on techniques such as animation retargeting to map captured or authored motion onto different skeletons on the fly, and on motion capture as a common source of the underlying motion data. It is a core requirement for games, virtual avatars and interactive XR experiences.
