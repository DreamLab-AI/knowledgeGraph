A location based service is a wireless-IP service that uses geographic information to serve a mobile user, or any application service that exploits the position of a mobile terminal [^1].

The SWEET ontology makes the class a subclass of its geospatial service and treats the abbreviation LBS as an equivalent class [^2]. The Open Geospatial Consortium standard on location services specifies interfaces that let companies in the value chain provide their pieces of applications [^3].

The OGC wording dates from a mobile terminal setting, and the retained sources do not establish how far it covers other positioning uses. They also give no service counts or performance figures.

[^1]: Open Geospatial Consortium, “OpenGIS Location Services (OpenLS): Core Services”. https://docs.ogc.org/is/07-074/07-074.pdf
[^2]: ESIP SWEET ontology (GitHub), “SWEET Representation Data Service Geospatial (Turtle)”. https://raw.githubusercontent.com/ESIPFed/sweet/master/src/reprDataServiceGeospatial.ttl
[^3]: Open Geospatial Consortium, “Location Service (OpenLS)”. https://www.ogc.org/standards/ols/
