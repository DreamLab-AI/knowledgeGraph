Radiometric accuracy is how closely a sensor's calibrated radiometric measurement agrees with the true radiance or reflectance it is meant to represent.[^1][^2]

NASA describes Landsat calibration as aiming to make imagery accurately reflect conditions on the ground and stay consistent across time and between sensors. The Landsat 9 sensor carries internal calibration sources and can use solar and lunar calibration to support radiometric accuracy and stability. The mission page lists radiometric accuracy among the fundamental mission requirements but, in the pages opened here, gives no accuracy figure.[^1][^2]

Accuracy is not the same as radiometric resolution. Landsat 9 records 14-bit data, which improves the ability to separate very bright and very dark surfaces, but that describes quantisation rather than closeness to a reference value.[^1]

A quality statement is only useful with a stated reference. The CEOS quality framework asks that indicators of quality be traceable to reference standards, preferably SI, so that users can judge suitability for an application, and the CEOS calibration and validation group gives access to reference data and agreed protocols. These sources do not set a universal accuracy threshold.[^3][^4]
