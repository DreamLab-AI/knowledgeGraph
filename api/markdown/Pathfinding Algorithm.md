
A computational algorithm that determines an optimal or near-optimal route between a start and goal node in a graph or spatial environment. Pathfinding algorithms are central to autonomous navigation, game AI, robotics, and metaverse movement systems, with classical examples including Dijkstra's algorithm for shortest paths and A* for heuristic-guided search in spatial graphs.
