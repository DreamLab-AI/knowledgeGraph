Flight software is the software that runs on a spacecraft's onboard computer and its subsystems to command it, process telemetry and manage its operation.[^1][^2]

A NASA survey of small-spacecraft avionics describes the command and data handling system as flight software running on the onboard computer, covering command and telemetry processing, real-time control from sensor inputs, network management and data storage. It also counts software on the subsystems and payload as part of flight software.[^1]

Earlier JPL accounts describe a central spacecraft computer that keeps time, interprets commands from Earth, formats telemetry and manages high-level fault protection and safing. Memory holds command sequences and executable programmes uplinked from Earth, which can be overwritten after use.[^2]

Available surveys show operating systems ranging from lightweight real-time systems to full Linux, with reusable frameworks such as the core Flight System, though mission-specific algorithms are still needed. Greater complexity raises verification effort, cost and schedule risk. Standard taxonomy of flight software layers is not established in sources, so boundaries should not be assumed.[^1]
