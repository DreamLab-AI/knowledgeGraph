A scattergram is a plot of paired values, one point per observation, and in remote sensing it is the two-band plot of pixel value pairs also called a feature space plot.[^1][^2]

SWEET places the class beneath Plot and gives it a label but no definition text.[^1] ITC, University of Twente, calls a graph that shows feature vectors a feature space, a feature space plot or a scatter plot, and says a two-dimensional scatterplot shows which pixel value pairs occur within a two-band image.[^2] Frequent combinations can be shown by intensity or colour, so the plot carries a count of occurrence as well as position.[^2]

With four or more bands the practical solution is to plot all possible combinations of two bands separately.[^2] The retained sources treat scattergram and scatterplot as one graph under different names, which is an inference from the two labels and not something either source states. They do not place scattergram production at any processing level, and the plot presents data without changing them.
