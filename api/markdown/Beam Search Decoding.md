- ### Definition
  - Beam search decoding is the inference-time procedure by which neural [[Large Language Models]] and [[Encoder Decoder Architecture]] models generate output sequences. At each generation step the model scores all vocabulary extensions for each active hypothesis, and only the top-k scoring continuations are propagated to the next step. The final output is the highest-scoring complete sequence from the beam, making the method more reliable than greedy decoding whilst remaining far cheaper than exhaustive search.

- ### Relationships
  - Beam search decoding [[uses]] [[Large Language Models]] as the scoring backbone that assigns probability to each token continuation. It equally [[uses]] [[Encoder Decoder Architecture]] models in seq2seq settings such as translation. The technique [[enables]] high-quality [[Machine Translation]] and deterministic [[Text Generation]]. It is [[relatedTo]] [[Sampling]] methods such as nucleus and top-k sampling, which trade determinism for diversity, and to [[Natural Language Processing]] as the broader disciplinary context.

- ### Content
  - Beam search decoding emerged as a practical necessity when neural machine translation models based on recurrent networks were first deployed at scale circa 2014–2016. Prior statistical MT systems had used beam search over phrase tables; the neural era preserved the algorithm but shifted its domain to log-probability scoring over a fixed vocabulary at each autoregressive step. Bahdanau's attention mechanism made beam search more effective by providing richer conditioning signals.

  - At a technical level, beam search decoding in transformer-based models involves computing the full vocabulary softmax at each step, selecting the top-k extensions for each of the k active hypotheses, yielding k² candidates, and retaining only the top-k overall. End-of-sequence tokens trigger finalisation of a hypothesis. Hyperparameters including beam width, length penalty (alpha), and minimum/maximum length are tuned per task. Techniques such as early stopping, no-repeat-ngram constraints, and forced decoding extend the basic algorithm.

  - The ecosystem supporting beam search decoding includes the Hugging Face `generate()` API, OpenNMT, FairSeq, and TensorFlow's seq2seq library, all of which expose beam width and related parameters directly. It is the standard decoding method for production translation APIs from Google, DeepL, and Microsoft, as well as for code generation models where correctness matters more than creativity.

  - By 2024–2025 beam search decoding faces competition from speculative decoding, which parallelises token generation, and from inference-time compute scaling methods that use repeated sampling and reward models to select the best output. For constrained domains such as formal verification, structured data extraction, and low-resource translation, beam search decoding retains a strong position due to its determinism and controllability.
