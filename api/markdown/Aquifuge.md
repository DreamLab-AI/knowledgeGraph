An aquifuge is a hydrogeologic unit with no interconnected openings, so it can neither store nor transmit water.[^1] It is the limiting case of low permeability, stricter than an aquiclude, which still stores water.[^1][^2]

The USGS glossary also lists the sense of an impermeable rock and points to confining unit as the preferred term.[^1] SWEET records the class as a direct subclass of hydrosphere feature with no further restriction.[^3]

Apart from the SWEET structure, the USGS glossary is the only retained source that defines this term, and it offers no worked example of a rock type that qualifies. A fully impermeable body is an idealisation, which the sources do not discuss.
