A mined data state is the condition of data that have been through a mining process, meaning the application of data analysis and discovery algorithms that produce patterns over the data.[^1] SWEET defines its mined class as a data state restricted by a had-process relation to a mining process.[^2]

Knowledge discovery literature treats data mining as one step in a wider process of identifying valid, novel, potentially useful and understandable patterns, so a mined state describes data after that step rather than the whole workflow.[^1]

SWEET supplies the structure but no prose definition, and retained sources do not establish how a mined state relates to processing levels of a satellite product or how it is recorded in product metadata.[^2]

[^1]: Ester et al., “Algorithms for Characterization and Trend Detection in Spatial Databases” (KDD-97). https://www2.cs.sfu.ca/~ester/papers/kdd_97.pdf
[^2]: ESIP Federation, “SWEET stateDataProcessing.ttl”. https://raw.githubusercontent.com/ESIPFed/sweet/master/src/stateDataProcessing.ttl
