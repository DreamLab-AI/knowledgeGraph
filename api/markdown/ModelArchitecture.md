### Major Architecture Families
- **Feedforward Networks**: Simplest architecture with unidirectional information flow, suited for structured data
- **Convolutional Neural Networks (CNNs)**: Specialized for grid-like data using filters and pooling layers (image processing)
- **Recurrent Neural Networks (RNNs)**: Designed for sequential data with temporal dependencies (text, time series)
- **Transformers**: Attention-based architecture enabling parallel processing, foundation for modern LLMs and vision models
- **Encoder-Decoder**: Two-stage architecture for sequence-to-sequence tasks (translation, summarization)
- **Generative Adversarial Networks (GANs)**: Dual-network architecture for generative tasks

### Hybrid Approaches
- CNN-RNN combinations for video understanding
- Transformer-CNN hybrids for vision tasks
- Attention-augmented architectures
