Terrestrial Time is a coordinate time whose mean rate is close to the mean rate of the proper time of an observer located on the rotating geoid, and it may be used as the independent time argument for geocentric ephemerides.[^1]

The IERS Conventions relate it to Geocentric Coordinate Time by a conventional linear transformation set by IAU 2000 Resolution B1.9.[^1] An accurate realisation is International Atomic Time plus 32.184 seconds, which Navipedia presents as a constant offset, so a realised value carries the uncertainty of the atomic time scale it is built on.[^1][^2]

Both sources record the naming history. The scale was called Terrestrial Dynamical Time before the IAU resolution of 1991 substituted the present terms.[^1][^2] Older literature may therefore use the earlier name for the same scale.

Terrestrial Time is a uniform scale for modelling, not a time of day. It is distinct from Universal Time 1, which is tied to the Earth's rotation, and from Coordinated Universal Time, which is kept close to that scale by leap seconds, and the sources here do not describe how any particular software handles the conversions.[^1][^2]
