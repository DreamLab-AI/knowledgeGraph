Measurement accuracy is the closeness of agreement between a measured quantity value and a true quantity value of a measurand.[^1]

The VIM states that accuracy is not a quantity and is not given a numerical value, and that a measurement is called more accurate when it has a smaller measurement error. The GUM likewise calls accuracy a qualitative concept.[^1][^2]

Accuracy is related to trueness and precision but is not the same as either. Both documents advise against using precision to mean accuracy, and the vocabulary advises against using accuracy for trueness. A figure quoted as accuracy in a data specification therefore usually stands for an error or uncertainty statement, and its definition should be read from the specification.[^1][^2]

In Earth observation, CEOS describes its calibration and validation work as aimed at long-term confidence in the accuracy and quality of data and products. That page does not define accuracy or give achieved values.[^3]
