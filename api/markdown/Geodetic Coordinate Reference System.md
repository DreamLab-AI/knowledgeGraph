A geodetic coordinate reference system is, in ISO 19111 as published by OGC, a three-dimensional coordinate reference system based on a geodetic reference frame and having either a Cartesian or a spherical coordinate system.[^1]

A geodetic reference frame supplies the position of the origin, the scale and the orientation of the axes, which ties the coordinates to the Earth.[^1] The same document calls a coordinate reference system with a geodetic reference frame and an ellipsoidal coordinate system a geographic one, so the narrower OGC use of geodetic differs from looser usage that applies the word to latitude and longitude on an ellipsoid.[^1]

Ordnance Survey makes the practical point that latitude and longitude only define a position on the surface of a stated ellipsoid, so the ellipsoid and its placement relative to the ground must be known before coordinates identify a place.[^2] GNSS fixes are three-dimensional and refer to a global datum, which for the OS Net reference stations is ETRS89.[^2]

A geodetic coordinate reference system says nothing by itself about heights above mean sea level. Orthometric height needs a geoid model in addition to the ellipsoid.[^2]
