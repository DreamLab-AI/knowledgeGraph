A map projection is a systematic transformation of the latitudes and longitudes of locations on a sphere or an ellipsoid into locations on a plane.[^1][^2]

The OGC specification phrases it as a coordinate conversion from an ellipsoidal coordinate system to a plane. The base system is usually a geographic one, and the result is a projected coordinate reference system with northing and easting while any ellipsoidal height is unchanged.[^2]

Snyder and Voxland describe projections by the properties they preserve. A conformal projection preserves angles at each point, and the Mercator projection is conformal and valid for navigation but distorts areas near the poles. A projection that has a desirable property can still be a poor choice for a given purpose, so the choice follows the intended use of the map.[^1]

A projection does not define a datum. The geographic system it starts from carries the datum, and the sources do not state parameter sets or distortion figures for any named projection here.[^1][^2]
