The ICVCM Framework is the governance framework established by the Integrity Council for the Voluntary Carbon Market to set quality benchmarks for carbon credits. Centred on the Core Carbon Principles and an associated Assessment Framework, it defines criteria for additionality, permanence, robust quantification, and transparent governance. The framework aims to restore trust and comparability across voluntary carbon-credit issuers.

### Content

- Credits assessed against the Core Carbon Principles earn a CCP label, signalling that they meet thresholds for additionality, no double counting, and sound governance. Tokenised carbon-market projects reference the framework to anchor on-chain assets to verifiable real-world climate outcomes.
