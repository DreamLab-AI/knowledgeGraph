GNSS availability is the percentage of time that the services of a navigation system are usable by the navigator.[^1]

Navipedia notes that the idea can be applied to different things: the availability of a usable signal from one satellite or orbital slot, or the availability of position, velocity and time from the whole constellation. A requirement can also add an error threshold, in which case the system counts as available only while the error meets it; the article says this makes sense only where the system supports integrity or a reference system can measure the errors.[^1]

The GPS Standard Positioning Service performance standard defines availability as the percentage of time that the service signals are available to a receiver, and expresses it on a per-satellite or per-constellation basis. Navipedia names the constellation configuration and the surrounding environment, such as buildings that mask part of the sky, as the main influences on what a user experiences.[^2][^1]

Availability is distinct from continuity and integrity, which describe uninterrupted operation and trust in the output. The sources give definitions and a measurement approach; they do not give availability figures for any current constellation or location, and a published service commitment should be read from the current version of the relevant standard.[^1][^2]
