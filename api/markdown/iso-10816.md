- ### Definition
  - ISO 10816 is the international standard for evaluating rotating-machine vibration via non-rotating-part measurements. It provides the severity thresholds that underpin [[Predictive Maintenance]] programmes.
- ### Content
  - The standard groups machines by class and defines RMS velocity zones (A through D) marking the boundary between healthy operation and the need for corrective action. Continuous vibration sensors compared against these zones let maintenance teams schedule interventions before failure. It has been progressively superseded by the ISO 20816 series.
