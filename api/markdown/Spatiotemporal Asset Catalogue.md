A spatiotemporal asset catalogue is an index of files that represent information about the Earth captured in a certain space and time, organised so that they can be searched by location and time.[^1][^2]

The STAC specification describes one common form. An item represents a single asset as GeoJSON, so the GeoJSON is a searchable record that references the files rather than the files themselves. Its stated examples of assets include satellite, aircraft and drone imagery, SAR, point clouds and data cubes.[^1]

STAC is presented as an open specification that grew from organisations working to make searching for satellite imagery interoperable, so that one search does not need a different tool for each provider.[^2]

A catalogue entry locates and describes an asset. The cited sources do not say that an entry confirms the asset is still available, or that its quality is adequate for a given use, and the STAC documents are used here for STAC only. Other catalogue designs may differ.[^1][^2]

[^1]: Radiant Earth, *STAC Overview*. https://raw.githubusercontent.com/radiantearth/stac-spec/master/overview.md
[^2]: STAC project, “About STAC”. https://stacspec.org/en/about/
