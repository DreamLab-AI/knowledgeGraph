- ### Definition
  - A cycloidal drive is a low-backlash, high-ratio reduction gearbox built from a [[Mechanical Component]] set in which a cycloidal disc rolls against pins to deliver compact, high-torque actuation.
- ### Content
  - Motion is generated by an eccentric input shaft driving a lobed disc whose rotation is transferred through output pins, yielding smooth high reductions in one stage. The many simultaneous contact points give excellent shock tolerance and durability, which is why cycloidal drives are widely used in industrial robot arms.
