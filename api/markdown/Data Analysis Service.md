A data analysis service is, in the SWEET ontology, a kind of data service, with analysis operations such as classification and clustering placed beneath it.[^1]

In the ontology, the class is a subclass of data service and lists classification, cluster and knowledge discovery among its subclasses.[^1]

A concrete example of the clustering kind is the Esri Iso Cluster tool, which uses an iterative optimisation procedure and is most often used in preparation for unsupervised classification.[^2] That shows an analysis operation offered as a software tool, not what any particular service interface looks like.[^2]

Retained sources include no prose definition of the class itself and no service interface standard, so the page defines it only through the ontology hierarchy and the example.[^1]
