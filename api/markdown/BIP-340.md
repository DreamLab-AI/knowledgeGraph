- ### Definition
  - BIP-340 defines the Schnorr [[Digital Signature]] standard for Bitcoin, enabling key aggregation and forming the cryptographic foundation for [[Taproot Assets]] and related [[Bitcoin Improvement Proposals]].
- ### Relationships
  - BIP-340 builds upon [[Elliptic Curve Cryptography]] and the secp256k1 curve already used by Bitcoin's legacy ECDSA scheme, producing a 64-byte [[Schnorr Signature]] that is both more compact and mathematically superior for multi-party protocols. It directly enables [[BIP-341]] (Taproot) and the [[BIP-340 Schnorr Keypair]] abstraction used in wallet implementations, and its key-aggregation properties are fundamental to threshold signing schemes based on [[Cryptographic Signature]] composition.
- ### Content
  - BIP-340 was developed as part of the Taproot soft fork activation in November 2021 and represents one of the most significant cryptographic upgrades to Bitcoin since its inception. Schnorr signatures, unlike ECDSA, satisfy a linear property that allows multiple public keys and their corresponding signatures to be combined into a single aggregate signature. This property is the basis for multi-signature and threshold-signature schemes that are indistinguishable on-chain from single-signature spends, dramatically improving privacy.

  - The specification encodes public keys as 32-byte x-only coordinates rather than 33-byte compressed points, saving one byte per key and simplifying the mathematical treatment of negation. Signing is deterministic, using a nonce derived from the private key and message via a tagged hash function, eliminating the class of vulnerabilities caused by poor randomness that famously affected early ECDSA implementations. Test vectors are embedded in the BIP to ensure all implementations produce identical outputs.

  - BIP-340 underpins the broader Taproot ecosystem: BIP-341 uses Schnorr for key-path spends, BIP-342 defines Tapscript which also relies on Schnorr verification, and the Lightning Network's PTLCs (point time-locked contracts) exploit Schnorr linearity for improved payment channel privacy. The efficiency gains are compounded at scale: a 2-of-3 multisig wallet spending via MuSig2 produces a transaction indistinguishable from a single-key spend, reducing fees and improving fungibility across the entire Bitcoin network.
