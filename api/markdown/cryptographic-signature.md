- ### Definition
  - A cryptographic signature is a mathematical construction that allows a signing party to attach an unforgeable, verifiable proof of origin and integrity to a message or transaction, providing both authenticity and non-repudiation. Signatures are computed from the message content and the signer's private key using an asymmetric cryptographic algorithm; any party possessing the corresponding public key can independently verify the signature without learning the private key. Common schemes include ECDSA, Ed25519, and RSA-PSS, each with distinct performance and security profiles relevant to their deployment context.

- ### Content
  - Cryptographic signatures are foundational to the security of distributed systems, enabling trust between parties who share no prior relationship. The signing process involves computing a cryptographic hash of the message, then applying an asymmetric transformation using the private key to produce the signature value. Verification inverts this using the public key, confirming both that the message has not been modified and that the private-key holder authorised it.
  - In blockchain networks, transaction signing is the mechanism by which token holders authorise transfers and smart contract interactions. Every on-chain transaction carries a signature generated by the sender's private key, and block validators verify these signatures before including transactions in the ledger. The elliptic-curve algorithms ECDSA (used in Bitcoin and Ethereum) and Ed25519 (used in Solana, Cosmos, and numerous other networks) dominate this space due to their compact signature sizes and fast verification.
  - Beyond blockchains, cryptographic signatures underpin secure email (S/MIME, PGP), code signing for software distribution, TLS certificate authentication, and verifiable credentials in decentralised identity systems. The security of all these applications depends on key management practices that prevent private key exposure or compromise.
