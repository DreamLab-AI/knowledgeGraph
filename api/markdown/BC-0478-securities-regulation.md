### Technical Details
Key classification frameworks include:
- **Howey Test (US)**: Investment of money, common enterprise, expectation of profits from others' efforts
- **EU MiCA**: Crypto-assets not qualifying as financial instruments
- **UK FCA**: Security tokens vs utility tokens distinction
- **Swiss FINMA**: Token categories (payment, utility, asset)

### Regulatory Approaches
- **US SEC**: Enforcement-driven approach classifying many tokens as securities
- **EU MiCA**: Creates separate crypto-asset category distinct from securities
- **Japan FSA**: Registration framework for crypto-asset exchanges
- **Singapore MAS**: Token-by-token classification approach

### Compliance Implications
- **Registration**: SEC registration or exemption for security tokens
- **Disclosure**: Prospectus requirements for token offerings
- **Trading Venues**: Licensed securities exchanges for security tokens
- **Accredited Investors**: Restrictions on who can purchase

### Security Token Infrastructure
- **STOs**: Security Token Offerings as compliant alternatives to ICOs
- **Transfer Agents**: Blockchain-based securities transfer tracking
- **Qualified Custodians**: Regulated custody for digital securities
- **Secondary Markets**: Licensed ATS platforms for security token trading
