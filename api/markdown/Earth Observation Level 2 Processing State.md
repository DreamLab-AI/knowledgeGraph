Earth observation Level 2 is the stage at which geophysical variables have been derived from Level 1 data, held in swath form rather than on a regular grid.[^1][^2]

SWEET's state data processing module defines Level2 as a processing level whose data have had a parameterization process and whose data model is a swath, and it declares L2 as an equivalent class of Level2.[^1] NASA describes the same step in the scheme of its data products as derived geophysical variables at the same resolution and location as the Level 1 source data.[^3]

This page names a state of data, while the Level 2 data product page names the packaged dataset that is in that state. The Metrologia review describes Level 2 data as estimates of geophysical variables on the sampling pattern of the Level 1 radiances, which fits the swath data model.[^4]

Retained sources do not establish how SWEET intends the parameterization restriction to be tested, and the SWEET file carries no definition text for Level2, so the retrieval reading above rests on the NOAA and NASA descriptions rather than on the ontology itself.[^1][^3]
