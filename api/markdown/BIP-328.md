BIP-328 is a Bitcoin Improvement Proposal defining the Hierarchical Deterministic Keys (HD Keys) using the Silent Payments-related and descriptor key formats for derivation, standardising how extended keys and key origins are encoded. It supports the unambiguous representation of key paths and fingerprints used by descriptor-based and Taproot-aware wallets. By standardising key encoding, it improves interoperability between wallets handling Taproot assets and multi-party setups.

### Content

- The proposal specifies how extended public/private keys, derivation paths, and master fingerprints are represented so that signing devices and software wallets can coordinate unambiguously. This is important for multi-party and Taproot-based asset workflows where key origins must be exactly reproducible across implementations.
