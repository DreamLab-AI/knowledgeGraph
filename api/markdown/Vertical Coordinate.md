A vertical coordinate is a value in a one-dimensional coordinate system used for gravity-related height or depth measurements.[^1]

Heights and depths are measured along the direction of gravity from a vertical reference surface. Such surfaces have historically been defined as mean sea level at one or more places over a period of time, and more recently a value of gravitational equipotential may be adopted by convention.[^1]

A vertical coordinate has meaning only relative to a vertical datum. NOAA describes geodetic vertical datums as generally used for land elevations and water level datums as a reference for bathymetric soundings on nautical charts.[^2]

According to the standard, gravity-related height is distinguished from ellipsoidal height, which belongs to a three-dimensional ellipsoidal coordinate system tied to a geodetic reference frame.[^1] The standard does not set out how each type of gravity-related height is modelled.[^1]
