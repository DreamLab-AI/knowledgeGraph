Calibration traceability is the property of a measurement result that allows it to be related to a reference through a documented, unbroken chain of calibrations, each of which contributes to the measurement uncertainty.[^1]

In the metrology vocabulary, traceability requires an established calibration hierarchy, and the reference may be a realisation of a unit, a measurement procedure or a measurement standard. It also says the reference should be specified together with the time at which it was used to establish the hierarchy.[^1] For satellite-derived data products, a QA4EO guide asks that a quality indicator be based on an assessment of traceability to an agreed reference standard, ideally SI, propagated through the data processing chain.[^2]

The CEOS Analysis Ready Data specification for surface reflectance treats SI traceability as a goal requirement and not a threshold requirement. It links traceability to an estimate of measurement uncertainty and asks for information on traceability and on sensor calibration to be reachable from the metadata.[^3] A product that meets only the threshold level therefore makes no claim of traceability.[^3]

Calibration and traceability are not the same thing. NASA describes Landsat calibration as keeping imagery consistent across time and between sensors, but that page is a programme description and does not set out a calibration chain or uncertainty budget for a given product.[^4] Traceability for a particular sensor or dataset would need that documentation, which none of these sources provides.
