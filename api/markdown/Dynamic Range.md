Dynamic range is the span of signal levels over which an Earth observation sensor can record useful measurements, from the faintest distinguishable signal to the brightest it can represent.[^1]

This retained source does not define the term, but does describe two related properties: quantisation depth and signal-to-noise ratio. Landsat 8 and Landsat 9 OLI data are recorded at 12 bits and 14 bits respectively, compared with 8 bits for the earlier TM and ETM+ sensors, which the source credits with finer detection of brightness values.[^1]

A higher signal-to-noise ratio means the sensor distinguishes true measurements from noise better, and the OLI page presents this alongside the greater bit depth as a design improvement.[^1] Bit depth sets how many levels can be recorded, while noise sets which levels are distinguishable, so the two should not be treated as the same quantity.

No numerical dynamic range for any instrument, or relation between bit depth and saturation limits, is given in the source, so this page does not establish it either.

[^1]: NASA Landsat Science, “OLI-2 Design”. https://landsat.gsfc.nasa.gov/satellites/landsat-9/landsat-9-instruments/oli-2-design/
