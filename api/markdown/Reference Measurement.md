A reference measurement is an independent measurement of a quantity, traceable to a recognised standard where possible, that is used as the basis for calibrating or validating a satellite observation.[^1][^2]

The CEOS quality framework asks that quality indicators be traceable to reference standards, preferably SI, and links this to uncertainty analysis and comparison. The CEOS calibration and validation group offers the community access to reference data, networks and internationally agreed protocols. None of the sources opened gives a single formal definition, so this description is drawn from how they use the term.[^1][^2]

For validation, a reference is usually collected on the ground and then related to the satellite footprint. A National Physical Laboratory report states that the sampling scheme must give an aggregated value that does not depend on the location of the samples, and it focuses on optical products over tropical forests.[^3]

A reference is not automatically adequate. NASA presents Landsat calibration as independently verified against ground conditions, but whether a given reference suits a given product depends on its uncertainty, representativeness and timing, which the sources do not settle in general.[^1][^2][^3][^4]
