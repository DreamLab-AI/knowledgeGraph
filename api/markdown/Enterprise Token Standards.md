## Core Standards

### Foundation Standards

#### ERC-20 (Fungible Tokens)
- Most widely used ERC standard
- Simplifies development, use, and exchange of Ethereum-based tokens
- Use cases: utility tokens, security tokens, stablecoins

#### ERC-721 (Non-Fungible Tokens)
- Enables unique digital assets with distinct properties
- Applications: artwork, collectibles, in-game items
- Revolutionised digital ownership representation

#### ERC-1155 (Multi-Token Standard)
- Hybrid approach for fungible and non-fungible assets
- Single smart contract managing multiple token types
- Efficient for gaming (currency + unique items)

## Enterprise-Focused Security Token Standards

### ERC-1400 (Security Tokens)
- Unified framework for security token operations
- Streamlined issuance, trading, and management
- Enterprise digital asset leverage

#### Use Cases
- Tokenized securities
- Real estate fractional ownership
- Supply chain finance (invoices, inventory)
- Art and collectibles provenance

### ERC-1404 (Compliant Tokenization)
- Asset tokenisation with legal compliance
- Trading restrictions enforced via smart contracts
- Securities regulation adherence
- Simplified security token management

### ERC-3643 (T-REX Standard)
- Achieved EIP Final status: 15 December 2023
- First standard for compliant tokenization approved by Ethereum community

#### Applications
- Corporate bonds and equity tokenisation
- Real estate fractional ownership
- Supply chain transparency tokens

## Additional Enterprise Standards

### ERC-4626 (Tokenized Vault Standard)
- Designed for yield-bearing vaults
- Standardised vault interface
- DeFi integration for enterprises

### ERC-884 (Identity Management)
- Self-sovereign identity token creation
- User-controlled digital identity management
- Enterprise identity verification
