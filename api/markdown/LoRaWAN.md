
LoRaWAN is a media-access-control protocol and network architecture for low-power wide-area networks, built on the LoRa physical layer's chirp spread-spectrum modulation. It connects battery-powered devices to gateways over distances of several kilometres at low data rates, with end-to-end encryption and adaptive data-rate management. LoRaWAN is widely used for long-range, low-throughput IoT telemetry such as cold-chain and environmental monitoring.

- ### Content
  - Devices operate in classes A, B, and C that trade downlink latency against power consumption, and an adaptive data-rate scheme balances range, airtime, and battery life. Star-of-stars topology routes traffic through gateways to a network server that handles deduplication, security, and application delivery.
