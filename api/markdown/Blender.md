- ## Key Features
	- **3D Modelling:** A comprehensive suite of modelling tools for creating, transforming, and editing your models.
	- **Sculpting:** Digital sculpting tools provide the power and flexibility required in several stages of the digital production pipeline.
	- **Animation & Rigging:** A production-ready camera and object tracking solution.
	- **Grease Pencil:** A revolutionary 2D animation tool that allows you to draw in 3D space.
	- **Rendering:** A powerful, unbiased rendering engine that offers stunning, ultra-realistic rendering.
	- **Simulation:** Create amazing simulations with industry-standard libraries such as Bullet and MantaFlow.
	- **Video Editing:** A built-in video sequence editor allows you to perform basic actions like video cuts and splicing, as well as more complex tasks like video masking or colour grading.
	- **Scripting:** With a rich Python API, Blender is highly customizable and can be extended with custom tools and add-ons.
	- **VFX:** A built-in compositor allows you to post-produce your renders without leaving Blender.

## XR and Metaverse Integration (2025)
- **PICO Partnership**: PICO has partnered with Blender Foundation as an official contributor to the Blender OpenXR development programme, optimising creative workflows for XR artists
- **XR Roadmap 2025/2026**: Active development includes Mac bindings support, Location Scouting features, and Advanced Locomotion navigation
- **Blender 5.0**: Introduces significantly improved Geometry Nodes support for volumetric data with bundles and closures
- **Metaverse Addon (Project Hermes)**: Plugin supporting content creation for multiple metaverse platforms
