Archived data state is the SWEET class for data that have undergone an archive process, modelled as a subclass of data state.[^1]

In the SWEET state of data processing module, Archived is declared an OWL class and a subclass of DataState.[^1] It is further restricted to things that had some Archive process, expressed through the hadProcess property.[^1] The file gives the formal axioms but no prose definition, so the meaning of the process has to come from elsewhere.[^1]

The OAIS reference model supplies that sense. It defines an archive as an organisation that intends to preserve information for access and use by a Designated Community.[^2] Read together, an archived state records that data have passed into such preservation, whereas the archive itself is an organisation or system described on its own page.[^1][^2]

This retained OAIS document is a historical issue of the recommendation, so it is used for the stable concept of an archive and not for current normative wording.[^2] The retained sources do not establish what checks a dataset must pass before it counts as archived, and they do not say how the state relates to the production status field in dataset metadata.[^1][^2]
