Cartographic generalisation is the selection and simplified representation of map detail appropriate to the scale or purpose of a map.[^1][^2]

The Esri white paper describes the process as extracting and reducing information from reality or source maps so that it represents a specific theme or a smaller scale.[^2] It lists operations such as eliminating features that are too small, simplifying line and boundary detail without destroying essential shape, and aggregating adjacent features into a new area feature.[^2] The same paper calls manual generalisation extremely subjective and time consuming, which is the stated reason for automating it.[^2]

Weibel and Dutton treat generalisation as a core function of GIS software because of requirements for scale-changing and thematic reduction.[^1] The SWEET ontology places generalization under both geospatial service and data reduction service.[^3]

Only a class hierarchy and a label come from the ontology, with no prose definition, and the retained sources do not establish scale thresholds or a single agreed list of operations.[^3] The definition quoted by Weibel and Dutton concerns maps, so its application to satellite raster products is not established here.[^1]
