- ### Definition
  - ERC-1155 is an Ethereum multi-token standard that allows a single smart contract to manage an arbitrary number of distinct token types — fungible, non-fungible, and semi-fungible — each identified by a uint256 token ID, with quantities tracked per address per ID. Pioneered by Enjin and formalised as EIP-1155, the standard introduces safeBatchTransferFrom for atomic multi-token transfers in a single transaction, substantially reducing gas costs compared to managing multiple separate ERC-20 or ERC-721 contracts. It is widely adopted in blockchain gaming, NFT collections, and on-chain economies that blend consumable items with unique assets.

- ### Content
  - ERC-1155 was proposed by Witek Radomski of Enjin in 2018 to address the limitations of deploying separate ERC-20 contracts for each fungible item type and separate ERC-721 contracts for each unique asset in a game economy. By consolidating all token types into one contract with a mapping of (address => (id => balance)), it dramatically reduces deployment gas costs and allows a single approval to cover the entire collection.
  - The safeBatchTransferFrom function accepts arrays of token IDs and amounts, enabling atomic multi-item trades — for example, swapping ten gold coins and one sword NFT in a single transaction. The onERC1155Received hook on receiving contracts provides the same safety guarantees as ERC-721's safeTransferFrom, preventing tokens from being locked in contracts that do not implement the receiver interface.
  - Semi-fungible tokens represent an important use case enabled by ERC-1155: a token ID can start as fungible (multiple identical copies, e.g., an event ticket) and transition to non-fungible (each redeemed ticket becomes unique). OpenSea, Rarible, and other NFT marketplaces support ERC-1155 natively. The standard also supports a uri function providing metadata URIs templated with the token ID, allowing off-chain metadata to be referenced efficiently for large collections without IPFS pinning each item separately.
