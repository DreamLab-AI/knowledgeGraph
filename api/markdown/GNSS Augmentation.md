GNSS augmentation is a method of improving the performance of a global navigation satellite system, such as its integrity, continuity, accuracy or availability, by using information external to the GNSS in the user's position solution.[^1]

Navipedia divides augmentation systems into those that supply integrity information and those that improve the accuracy of the user solution. Within the first group the augmentation data comes either from satellites, as in satellite-based augmentation systems, or from the ground, as in ground-based augmentation systems. The second group includes differential GNSS and its real-time kinematic variants, which use reference-station networks, and precise point positioning, which uses fewer stations.[^1]

EUSPA describes EGNOS as a satellite-based system intended to let GNSS signals serve safety-of-life uses such as aviation approaches, while Navipedia describes precise point positioning as combining precise satellite orbits and clocks with dual-frequency pseudo-range and carrier-phase observables. These examples show that augmentation covers both integrity-oriented services and precision-oriented corrections, and that the two should not be treated as interchangeable.[^2][^3]

Sources do not establish the performance of any particular augmentation service. Coverage, latency, accuracy and approval for a given operation depend on the service, receiver and operating rules, and Navipedia's classification is a teaching scheme rather than a regulatory one.
