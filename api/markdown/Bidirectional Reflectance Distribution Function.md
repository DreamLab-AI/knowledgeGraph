A bidirectional reflectance distribution function specifies how a surface scatters light into a given viewing direction as a function of the illumination geometry, the view geometry and the wavelength.[^1][^2]

The MODIS user guide states that the Earth's surface scatters radiation anisotropically, especially at the shorter wavelengths that characterize solar irradiance.[^1] A NASA laboratory report says the function provides the reflectance of a target in a specific direction as a function of illumination and viewing geometry, and that it reflects the structural and optical properties of the surface.[^2]

The MODIS product MCD43A1 stores model weighting parameters for this function, produced daily from 16 days of Terra and Aqua data at 500 metre resolution, and those parameters are used to derive the Albedo and Nadir BRDF-Adjusted Reflectance products.[^3] The catalogue's seed reference, the NASA page on data processing levels, does not define the function, and the retained sources do not establish it as a processing level in its own right.
