### Technical Details
Key characteristics include:
- **Permissioned Access**: Only pre-authorized users and nodes can participate
- **Shared Governance**: Equal control and decision-making authority among consortium members
- **Data Privacy**: Only authorized members access the system, ensuring secure and tamper-proof data
- **Faster Consensus**: Limited node participation enables higher transaction throughput

### Major Platforms
- **Hyperledger Fabric**: Linux Foundation modular blockchain with IBM and SAP contributions
- **R3 Corda**: 300+ member consortium focused on financial services
- **Quorum**: J.P. Morgan enterprise platform for high-speed private transactions

### Industry Applications
Finance (R3 Corda for regulatory compliance), supply chain (Walmart/IBM using Hyperledger Fabric), and healthcare benefit from consortium blockchain's balance of transparency and privacy.

### 2024 Context
Hyperledger Foundation became part of Linux Foundation Decentralized Trust (September 2024), consolidating 17 code bases under unified governance.
