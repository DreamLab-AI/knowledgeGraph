
A satellite gateway is an earth-station facility that connects a satellite network to terrestrial networks or operator infrastructure.

In a broadband architecture, a gateway commonly provides a feeder-link interface and routes traffic between the satellite system and internet or private-network infrastructure. The facility may include antennas, RF equipment, modems, routing, terrestrial backhaul and operational systems; its function is not defined by dish size alone. User terminals serve endpoints, while gateways serve a network-side role.[^1][^3]

Some architectures separate feeder and user links, and designs may distribute functions across satellites. ESA’s Hylas page records a historical ground-segment arrangement using sites at Goonhilly and Land’s End. ESA’s MARIS page explores a proposed multi-satellite feeder/user-link concept. These are architecture examples, not evidence that every current network uses those arrangements.[^3][^4]

In the UK, Ofcom’s NGSO fixed-satellite-service guidance distinguishes a gateway earth-station licence from a network licence for user terminals. Its regulatory statement explains that Ofcom licences UK earth-station spectrum use, not the operation of the satellite itself. Licence scope depends on the station, band and conditions; authorisation does not by itself establish that a network is launched, fully deployed or serving customers.[^1][^2]

The Ofcom register retrieved on 2 October 2026 listed authorised gateway and network entries. Such an entry establishes the published authorisation status, not service readiness. Likewise, UK Space Agency’s ARTES ground-station innovation guidance describes a 2025 call window and possible funding; it does not establish an award or delivered gateway capability.[^1][^5]
