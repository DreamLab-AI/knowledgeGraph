In satellite navigation, the user segment is the part of a navigation system made up of receivers that use the broadcast signals, and in the GPS architecture it is one of three segments alongside the space segment and the ground segment.[^1]

Navipedia describes the GPS user segment as GPS receivers. Their main function is to receive GPS signals, determine pseudoranges and other observables, and solve the navigation equations to obtain coordinates and a very accurate time.[^1]

Interface control documents define the boundary between the space and user segments, and the GPS Architecture page names IS-GPS-200 for the first two radio links and IS-GPS-705 for the fifth. Each GNSS has its own time reference to which the elements of the space, control and user segments are synchronised.[^1][^2] The sources do not say how that synchronisation reaches an individual receiver.

Retained sources describe GPS only. They do not establish a general definition that covers other navigation systems, or non-navigation missions where users might mean data users, and they do not describe antennas or application equipment as part of the segment.

[^1]: ESA Navipedia, “GPS Architecture”. https://gssc.esa.int/navipedia/index.php/GPS_Architecture
[^2]: ESA Navipedia, “Time References in GNSS”. https://gssc.esa.int/navipedia/index.php/Time_References_in_GNSS
