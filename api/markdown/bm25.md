- ### Definition
  - [[BM25]] is a probabilistic sparse retrieval ranking function that scores document relevance to a query by combining inverse document frequency weighting with saturation-clipped term frequency and document-length normalisation, forming the foundational lexical baseline for [[Information Retrieval]] systems and a critical component of hybrid [[Retrieval Augmented Generation - RAG]] pipelines.

- ### Relationships
  - [[BM25]] is a specialisation of the [[Search Algorithm]] class and operates on an inverted [[Search Index]] that maps terms to document postings. It contrasts with [[Semantic Search]], which uses [[Embeddings]] from [[Natural Language Processing]] models rather than exact term matching, but complements it in hybrid retrieval pipelines where both sparse and dense signals are fused for higher recall and precision. [[Enterprise Search]] platforms and [[Retrieval Augmented Generation - RAG]] systems routinely use BM25 as a first-stage retrieval pass before neural re-ranking.

- ### Content
  - BM25 was developed as part of the Okapi information retrieval system at City University London by Stephen Robertson, Karen Spärck Jones, and colleagues throughout the 1970s to 1990s, with the final BM25 formulation published around 1994. The "BM" stands for "Best Match" and the "25" is simply the iteration number within the research programme. It was built upon the probabilistic relevance model, which treated retrieval as a probabilistic inference problem: given a query, what is the probability that each document is relevant? The BM family of functions provided a theoretically grounded way to estimate this probability using term statistics derived from the corpus.

  - The BM25 scoring function for a query Q with terms q1...qn and document D is: score(D,Q) = Σ IDF(qi) · (tf(qi,D) · (k1+1)) / (tf(qi,D) + k1 · (1 - b + b · |D|/avgdl)), where tf(qi,D) is the term frequency of qi in D, |D| is the document length in words, avgdl is the average document length in the corpus, IDF(qi) is the inverse document frequency of qi, k1 is the term frequency saturation parameter (typically 1.2–2.0), and b is the length normalisation parameter (typically 0.75). The k1 parameter controls how quickly additional occurrences of a term contribute diminishing returns to the score, while b controls the degree to which longer documents are penalised relative to average-length documents.

  - BM25 underpins the relevance ranking in major open-source search engines including Elasticsearch (which adopted BM25 as its default in version 5.0, replacing TF-IDF) and Apache Solr. Its computational efficiency — requiring only integer arithmetic over inverted index postings — makes it suitable for millisecond query latency over corpora of billions of documents. The function handles vocabulary mismatch gracefully for exact-match retrieval but cannot capture semantic equivalence between synonymous terms or paraphrases, which motivates its combination with dense neural retrieval.

  - In the 2024-2025 period, BM25 retains central relevance as the sparse component in hybrid retrieval architectures. RAG systems for large language models combine BM25 first-stage retrieval (high speed, high precision for keyword queries) with dense embedding similarity search (high recall for semantic queries), fusing ranked lists via reciprocal rank fusion or learned query routers. BM25 also serves as the gold-standard baseline for academic information retrieval benchmarks such as MS MARCO, BEIR, and TREC. Variants including BM25+ (addressing the IDF lower bound problem) and BM25L (with alternative length normalisation) address documented limitations. Despite the ascendance of neural retrieval, BM25 persists because it is interpretable, requires no training data, generalises immediately to new domains, and is computationally two to three orders of magnitude cheaper than embedding-based retrieval.
