A gazetteer is a dictionary of named places that records the location of each entry, and a gazetteer service is a network-accessible way of querying one.[^1][^2]

Natural Resources Canada quotes the ISO definition of a gazetteer as a dictionary of instances of a class or classes of features containing some information regarding position, and describes it as a geospatial dictionary of geographic labels with their locations and other descriptive information.[^1] The OGC profile describes a Gazetteer Service as a specialised Web Feature Service, and requires feature types derived from SI_LocationInstance.[^2]

SWEET classes Gazetteer under both DiscoveryService and GeospatialService, which places it among services rather than data products.[^3] Natural Resources Canada states that the OGC Gazetteer best practice document is not an OGC standard.[^1]

A gazetteer system may also include the capability to geocode.[^1] The retained sources do not establish how gazetteers are used in Earth observation processing chains.
