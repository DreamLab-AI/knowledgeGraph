Visualization is the data analysis service that renders data as images, plots or maps so that people can inspect them.[^1][^2]

SWEET classes the term as a kind of data analysis service and treats its verb form as equivalent.[^1] Earth observation portals show the practice: NASA's Worldview is described as a tool for interactively browsing, comparing, animating and downloading rendered satellite data products.[^2]

A second NASA tool, Giovanni, displays and analyses geophysical parameters in remote sensing data where the data lineage is known.[^3] That wording ties display to analysis in one service, which matches the SWEET placement under analysis rather than under data storage.[^1][^3]

Retained sources give no taxonomy of visualisation types, any quality standard for portrayal, or whether a rendered image counts as a data product in its own right. Worldview and Giovanni are two examples from one agency, not a survey of practice.[^2][^3]

[^2]: NASA Earthdata, “Worldview”. https://www.earthdata.nasa.gov/data/tools/worldview
[^3]: NASA Earthdata, “Giovanni”. https://www.earthdata.nasa.gov/data/tools/giovanni
