A spatial reference system is a set of conventions that ties positions to the real world, which in modern geodesy is called a reference system and is made usable through a reference frame.[^1]

A spatial reference is described as a description of position in the real world, and it may take the form of a label, code or coordinate tuple. References fall into two categories, those using coordinates and those based on geographic identifiers. The referencing-by-coordinates standard covers only the first category and leaves identifier-based referencing to a separate standard.[^1]

For the Earth, the fundamental conceptual system is the International Terrestrial Reference System, which has been realised through several versions of the International Terrestrial Reference Frame. The sources keep the two terms apart: the system is the set of conventions and the frame is its realisation through points with determined coordinates.[^1]

Datums are described by NOAA as the basis for all geodetic survey work. In the United States there are horizontal datums for latitude and longitude and vertical datums for elevations and depths, so a full spatial reference commonly combines more than one component. The NOAA page is a national explainer and does not define the general term.[^2]
