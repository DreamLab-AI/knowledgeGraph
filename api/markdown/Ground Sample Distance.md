Ground sample distance is the separation between the centres of two adjacent samples on the ground.[^1][^2]

It is one of several quantities that are called spatial resolution. The sources distinguish it from the pixel size of a gridded image in a map projection and from the footprint of the sensor, which is defined by the full width at half maximum of the detector’s line spread function.[^1][^2]

Because GSD describes the spacing of samples, it does not by itself state the size of the smallest object a sensor can distinguish. The sensor footprint and an effective resolved distance describe that, and the sources compare the footprint with the pixel size to judge over-sampling or under-sampling. A figure quoted as resolution therefore needs to be checked for which definition it uses.[^1][^2]

Neither retained source gives the relation between GSD and altitude, focal length or viewing angle, which depends on the sensor geometry and is not stated here. Both sources come from one NASA research group.[^1][^2]
