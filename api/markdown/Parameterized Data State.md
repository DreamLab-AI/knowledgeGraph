A parameterized data state is the condition of data after a parameterization has been applied, so that some process is represented by parameters instead of being resolved explicitly.[^1][^2]

Parameterization takes its meaning from model practice, where physical effects are represented by oversimplified parameters and where sub-grid scale processes are replaced by relationships with model-resolved variables.[^1][^2] A state of this kind therefore carries the approximation of the chosen representation, and it differs from a state that records only that data have been converted to other variables or formats.

NASA labels its products by processing level, with Level 2 holding derived geophysical variables at the same resolution and location as the source data and Level 4 holding model output or analysis results.[^3] The retained sources do not say which of these levels, if any, corresponds to a parameterized state.

None of the retained sources defines a data state of this name, and none gives figures, so the page rests on the definition of the process that leads to the state.[^1][^2][^3]
