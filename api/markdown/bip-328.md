- ### Definition
  - BIP-328 standardises hierarchical deterministic key derivation and encoding formats used by modern descriptor wallets, supporting interoperability for [[Taproot Assets]].
- ### Content
  - The proposal specifies how extended public/private keys, derivation paths, and master fingerprints are represented so that signing devices and software wallets can coordinate unambiguously. This is important for multi-party and Taproot-based asset workflows where key origins must be exactly reproducible across implementations.
