A clustered data state is the condition of data that has been through a clustering process.[^1]

In the SWEET ontology the class is a subclass of data state, restricted to data that had a process of the clustering type.[^1] SWEET treats cluster as equivalent to clustering and as a kind of data analysis service.[^2]

Clustering in remote sensing divides pixels into groups by natural groupings in their spectral values. A NASA report describes unsupervised classification as dividing a large number of pixels into classes based on natural groupings present in the image, usually by clustering methods.[^3] The Esri Iso Cluster tool separates all cells into a user-specified number of groups in the multidimensional space of the input bands.[^4]

Retained sources do not establish how a product records this state in metadata, nor which clustering method it implies. The ontology gives the restriction but no prose definition.[^1]
