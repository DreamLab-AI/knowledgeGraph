An Earth observation Level 1A data product is reconstructed, unprocessed instrument data at full resolution that is time-referenced and annotated with ancillary information.[^1]

NASA says the ancillary information can include radiometric and geometric calibration coefficients and georeferencing parameters such as platform ephemeris. The definition describes annotation of the data, and the page does not state that those coefficients have already been applied.[^1]

Sentinel-2 provides a mission-specific example. Its Level-1A processing initialises a viewing model from precise orbit determination products, decompresses the instrument source packets, handles the arrangement of shortwave infrared pixels and compresses the imagery with JPEG2000.[^2] This is not the same wording as the NASA definition, so the two should be compared before products from different agencies are treated as equivalent.[^1][^2]

Not every mission publishes a Level 1A product, and the sources opened here do not say how many do.[^1]

[^1]: NASA Earthdata, “Data Processing Levels”. https://www.earthdata.nasa.gov/learn/earth-observation-data-basics/data-processing-levels
[^2]: ESA Copernicus SentiWiki, “Sentinel-2 Processing”. https://sentiwiki.copernicus.eu/web/s2-processing
