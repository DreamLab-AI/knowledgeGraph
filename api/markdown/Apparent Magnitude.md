Apparent magnitude is a logarithmic measure of how bright an astronomical object looks from Earth, on a scale in which a larger number means a fainter object.[^1]

Hipparchus sorted stars into six brightness classes, and the modern system descends from them. It was later made exact so that a difference of five magnitudes corresponds to a brightness ratio of 100:1.[^1]

Because it records how bright an object appears, it depends partly on distance and so cannot by itself separate a nearby faint object from a distant luminous one. Absolute magnitude, defined at a fixed distance, is used to remove that dependence.[^2][^3]

Magnitudes are mainly used in visual and optical astronomy. Radio, infrared, X-ray and gamma-ray astronomers generally express brightness as energy per unit area per second instead, and the source does not claim that a magnitude can be converted between bands without further information.[^1]
