Spacecraft redundancy is the provision of backup components, with means to reroute function to them, so that a spacecraft can maintain or restore function after a component fails.[^1]

NASA states that most components on which mission success depends have redundant backups, which can be brought into use autonomously or by real-time command. It attributes the extended missions of several deep-space spacecraft to on-board redundant transmitters, receivers, tape recorders, gyroscopes and antennas.[^1]

NASA's small-spacecraft survey treats redundancy as a design choice: an avionics system can be single-string or redundant, depending on required performance, bandwidth, environmental robustness and risk tolerance.[^2]

Standards reflect the practice. The ECSS standard for MIL-STD-1553B addresses devices on a single, redundant data bus, and the ECSS testing standard includes requirements for redundancy testing. The sources do not set out redundancy schemes or reliability figures.[^3][^4]
