Geodetic latitude is the angle from the equatorial plane to the perpendicular to the reference ellipsoid through a given point, with northwards treated as positive.[^1][^2]

OGC gives ellipsoidal latitude as a synonym and defines spherical latitude separately as the angle measured from the centre of the ellipsoid.[^1] The sources opened here do not state how far the two differ, so the page makes no numerical claim about it.

Latitude locates a point on the surface of a stated ellipsoid. Real points lie above or below that surface, so a third coordinate, ellipsoid height, measures the distance along the perpendicular to the ellipsoid.[^2] Ordnance Survey stresses that ellipsoid height is not true height because it is not related to a level surface.[^2]

Geodetic latitude values are tied to the ellipsoid and datum in use, so a coordinate quoted without them is ambiguous.[^2]
