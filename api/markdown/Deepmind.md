## Key Products and Research
- **Gemini**: Family of multimodal large language models (Gemini 2.5, Gemini 3, Gemini 3 Flash in 2025)
- **AlphaFold**: Nobel Prize-winning protein structure prediction (240M+ protein structures predicted)
- **AlphaGo/AlphaZero**: Game-playing AI systems
- **AlphaProteo**: Novel protein design with specific binding properties
- **AlphaMissense**: Prediction of harmful genetic mutations
- **AlphaEvolve** (May 2025): Evolutionary coding agent using LLMs for algorithm design
- **Imagen**: Text-to-image generation
- **Veo**: Text-to-video generation
- **Lyria**: Text-to-music generation
