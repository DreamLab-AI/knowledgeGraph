- ### Definition
  - ERC-721 is the Ethereum token standard that defines the interface for non-fungible tokens (NFTs), where each token is uniquely identified by a uint256 token ID and an associated owner address recorded on-chain. Unlike ERC-20 fungible tokens, which are interchangeable, each ERC-721 token is distinct and cannot be exchanged equivalently for another. The standard defines a minimal interface including ownership transfer, approval delegation, and balance queries, plus an optional metadata extension that associates each token with a URI resolving to off-chain JSON metadata including name, description, and image. ERC-721 is the foundational standard for digital art, collectibles, gaming items, and tokenised real-world assets on Ethereum.

- ### Content
  - ERC-721 was proposed by William Entriken, Dieter Shirley, Jacob Evans, and Nastassia Sachs and finalised as an Ethereum standard in 2018. It provides the canonical interface for representing ownership of unique digital assets on Ethereum. The core interface specifies functions for querying ownership (`ownerOf`), transferring tokens (`transferFrom`, `safeTransferFrom`), and delegating transfer approval (`approve`, `setApprovalForAll`), along with events (`Transfer`, `Approval`) that index ownership changes for off-chain indexers and NFT Marketplace frontends.
  - ERC-721's metadata extension (`tokenURI`) returns a URI for each token that conventionally resolves to a JSON object describing the asset's name, description, and image or animation URL. These metadata URIs commonly point to IPFS or Arweave for decentralised storage, though centralised hosting remains common. The security of the NFT therefore depends on both the Smart Contract's ownership record and the persistence of the off-chain metadata.
  - The standard became central to the NFT boom of 2020-2022, with collections such as CryptoPunks and Bored Ape Yacht Club demonstrating large-scale commercial interest in digital ownership of unique assets. ERC-721 has since been complemented by ERC-1155, which supports both fungible and non-fungible tokens in a single contract — more efficient for gaming inventory. ERC-721 is also being adopted for tokenisation of real-world assets such as property deeds, event tickets, and intellectual property licences, where the unique on-chain identifier provides a tamper-evident ownership record on the distributed ledger.
