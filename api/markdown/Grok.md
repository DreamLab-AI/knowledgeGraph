## Technical Details

### Model Evolution
- **Grok-1** (Nov 2023): Initial release, basic conversational capabilities
- **Grok-1.5** (Mar 2024): Improved memory and logical reasoning
- **Grok-2/2 mini** (Aug 2024): Significant benchmark improvements
- **Grok-3** (Feb 2025): 10x compute vs Grok-2, trained on Colossus (200,000 GPUs)
- **Grok-4/4 Heavy** (Jul 2025): Flagship models with multi-agent capabilities

### Key Features
- **Think Mode**: Step-by-step reasoning for complex queries
- **Big Brain Mode**: Enhanced reasoning for math, science, coding
- **DeepSearch**: Web search integration for detailed responses
- **Aurora**: Photorealistic image generation with fewer restrictions (Dec 2024)
- **Grok Vision**: Real-time camera analysis on mobile devices
- **Voice Mode**: Multilingual audio with real-time search

### Benchmark Performance (Grok-3)
- AIME 2025: 93.3% (complex mathematics)
- GPQA: 84.6% (graduate-level expert reasoning)
- LiveCodeBench: 79.4% (coding challenges)

### Training Infrastructure
Colossus supercomputer: ~200,000 NVIDIA GPUs, one of the world's largest AI training clusters

## Applications

- **Conversational AI**: General knowledge Q&A with witty personality
- **Real-time Analysis**: Access to trending X/Twitter data
- **Coding Assistance**: Strong programming capabilities
- **Image Generation**: Aurora for photorealistic and creative images
- **Research**: Scientific and mathematical problem-solving

## Access and Pricing

- Grok 3 (Fast) and Grok 4 (Expert): Free for X users with limits
- SuperGrok: $30/month for single agent
- SuperGrok Heavy: $300/month for multi-agent Grok 4 Heavy
- Standalone apps: iOS and web (global since Jan 2025)
