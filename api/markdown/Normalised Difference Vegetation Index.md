The Normalised Difference Vegetation Index is the vegetation index formed by dividing the difference between near-infrared and visible reflectance by their sum.[^1][^2]

NASA describes healthy vegetation as absorbing most of the visible light that reaches it and reflecting a large portion of the near-infrared light, which is the contrast the index exploits.[^1] Sentinel Hub describes the same index as normalising green leaf scattering in near-infrared wavelengths against chlorophyll absorption in red wavelengths, and calls it a good proxy for live green vegetation.[^2] The band pair depends on the sensor, as the list of formulae per dataset on the Sentinel Hub page shows.[^2]

NASA states that the value for a pixel ranges from minus one to plus one and that no green leaves gives a value close to zero.[^1] The two sources describe surface classes in slightly different value bands, so thresholds for barren ground, shrubland or forest should be taken from the documentation of the product in use, not from this page.[^1][^2]

NASA uses the index as an indicator of agricultural drought because vegetation growth is limited by water in most climates, and it also lists exceptionally cold temperatures as another cause of lower than normal values.[^1] The retained sources do not establish how the index saturates in dense canopies, how atmospheric or soil effects are corrected, or the accuracy of any particular product.
