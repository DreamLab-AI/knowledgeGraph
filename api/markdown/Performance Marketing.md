Performance marketing is a digital advertising strategy where advertisers pay for specific, measurable actions such as clicks, leads, or completed transactions rather than for impressions.

### Overview

- **[Emerging signal]** OpenAI should shift from a pay-for-attention model (cost per click/view) to a pay-for-results model where advertisers pay only upon verified transaction completion and user satisfaction. *(Source: Host, via AI Daily Brief, 2026-08-24)*
