A minimum valid data value is the smallest value of a variable that generic applications should treat as valid data.[^1] Values below it are not valid data, and the convention offers a valid range attribute that gives the minimum and maximum together.[^1][^2]

When a variable is packed, the limit is expressed in the packed domain, so that it can be applied before any scale factor or offset.[^1][^2] SWEET records the minimum valid class as a subclass of its value class, which matches the asserted parent of this page.[^3]

Retained sources do not establish how a valid minimum is chosen for a given sensor, nor whether it reflects instrument physics or product design.
