Brightness temperature is the temperature of a blackbody that would emit the same radiance as the observed radiation at a specified frequency and direction, expressed in kelvin.[^1][^2]

NIST Technical Note 1551 gives this for unpolarized radiation, and for polarized radiation it applies the same statement to each polarization separately.[^1] In the Rayleigh-Jeans limit the microwave power per unit bandwidth received by a radiometer is P=k Tb, where k is Boltzmann's constant.[^1]

NOAA describes brightness temperature as a passive measurement of radiance from the microwave radiation emitted from the atmosphere, represented in units of temperature.[^2] The same page lists the AMSR-2 brightness temperature products as Level 2 products produced from Level 1B data.[^2] The NASA processing levels page cited as the catalogue seed does not define the term, and the retained sources do not establish how brightness temperature differs from the physical temperature of a real surface.

[^1]: NIST and IEEE GRSS, “Recommended Terminology for Microwave Radiometry (NIST Technical Note 1551)”. https://www.grss-ieee.org/wp-content/uploads/2009/09/TN1551.pdf
[^2]: NOAA, “AMSR-2 Microwave Brightness Temperatures”. https://vlab.noaa.gov/web/towr-s/amsr-2-mbt
